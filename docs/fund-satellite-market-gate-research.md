# 市场方向、广度与趋势增配开关

## 结论

**本轮三种简单市场开关仍没有解决稳健性问题，不建议直接采用。** 8个股票主题池中，广度开关失效后退出取得69.0282%收益、8.2186%最大回撤，优于同池原静态60.8898%/8.3501%；但现代12主题池同一规则只有37.1584%/9.0257%，不如原静态39.7892%/8.7135%。

再统一投资起点、初始资金及债券配置后，8主题池的该规则也落后于静态。原8主题账户延续持有时，同一近期区间仍有小幅优势，所以不能简单归因于“收益全来自早期”：起始持仓、此前状态及观察节奏都影响结果。不能只拿69%那一行推荐投资。

主报告：`runtime/verification/satellite-market-gate-research-v1.json.gz`；统一口径诊断：`runtime/verification/gate-universe-alignment-v1.json.gz`。两份方案分别为`config/satellite-market-gate-research-v1.json`及`config/gate-universe-alignment-v1.json`。净值截至2026-10-12。

## 三种开关

- `direction_entry`：股票类等权每日收益信号的过去21、63交易日对数收益均为正，才允许新一轮趋势增配。
- `wide_entry`：在上述方向条件上，再要求至少60%的股票基金总收益净值高于自身120日均值。黄金、债券不进入广度。
- `wide_exit`：采用同一入场开关；每5交易日观察时开关失效，则撤回额外增配到中性核心，包括尚未完成资金修复的意图，普通持有期规则仍生效。

股票类等权曲线只是观察信号，不当作免费可交易组合。只读当时及此前的数据，不读取事后年份或牛熊标签。60%是本轮固定研究假设，未搜索最赚钱阈值；不同池对应离散人数为2/2、2/3、5/8、8/12，不能假装强度完全相同。

这里的方向和广度来自所选基金池，不是全A股市场的独立指标。扩充基金会改变开关本身，不能把本轮失效解释为所有市场择时方法都无效。

入场型开关只约束最初请求，不取消此前已经进入的资金修复意图；失效退出型也只在规定观察日触发。既有排队订单继续兑现。每日资产自身失效和实际风险检查仍优先；终端计费之外，没有因为市场开关全账户平仓。

其他规则保持上一轮20日方案：逆波动股票/黄金核心、债券40%、最多10个百分点股票内部增配、35%单只上限、过去10%波动约束、资金实际到账后修复、实际额外敞口观察后计时20日、退出后5日等待并恢复到核心容差带。关掉增配仍持有核心，不假设现金利息。

## 随机与压力检查

每种开关都以相同门槛、退出和现金规则跑32组固定随机选择，不选最好的种子。8主题失效退出跑赢31/32组随机序列，比随机中位数多7.0943个百分点；现代池只跑赢8/32组，比随机中位数少1.3506个百分点。2宽基池三种规则均与随机中位数相同，没有选择空间的结果不能证明排序有效。

现代失效退出在普通每边50/100基点费用下，分别落后相同情景原静态5.1535/7.8043个百分点；5/10/15日观察偏移分别落后3.7276/0.9013/3.2203个百分点；两交易日后执行落后4.0883个百分点。六个压力情景全落后。8主题池六个情景中五个胜出，但每边100基点仍落后4.4752个百分点。

32个路径只用于当前历史的条件随机对照，不是32段独立市场历史。百分位不是p值、统计显著性或未来成功概率。

## 统一口径诊断

三组均在2024-07-29以新资金10万元开始，保留完整过去信号预热、相同费用、初始观察和执行规则。8主题原本只有纯债，现代池包含纯债、短债、长期国债，因此另建立现代池仅保留同一纯债基金的对照。

| 同期新账户 | 原静态收益/回撤 | 无开关20日收益/回撤 | 失效退出收益/回撤 |
| --- | ---: | ---: | ---: |
| 8主题+黄金+纯债 | 43.5470 / 7.8138 | 40.8001 / 8.8278 | 37.3864 / 8.1457 |
| 12主题+黄金+同一纯债 | 39.6708 / 8.9455 | 38.0015 / 10.2852 | 35.2199 / 9.1158 |
| 12主题+黄金+三类债券 | 39.7892 / 8.7135 | 41.9760 / 10.7886 | 37.1584 / 9.0257 |

同一近期区间，原8主题账户延续持有时：失效退出43.1847%、原静态41.2787%；重置新资金及观察起点后则为37.3864%对43.5470%。**这不是同一初始持仓或同一内部状态的配对实验**，不能把差额全部归因于某个机制，但清楚表明从指定历史日期启动的好结果并非对任意新投资起点稳健。

现代三债无开关方案高于纯债对照约3.97个百分点，也说明只看板块排序会混入债券配置和账户路径影响，不能把组合收益全部归于排序。

## 验证与后续

主研究653次运行：28个旧主账户与16个已保存随机账户兼容回放、12个新开关主账户、144个压力账户、69个分段新账户、384个随机账户。统一口径另12次，共665次。所有资金、FIFO、费用、分红及资产核账通过，市场方向、股票广度、开关/状态转换及非动作从原始过去数据独立重建。

28个旧主账户、16个旧随机完整路径保持不变；统一口径4个现代原账户也精确匹配，保存的整数周期键按JSON边界转成字符串后比较完整每日记录，没有放宽金额或数值容差。相关回归166项通过，不代表全仓测试。两份报告的源快照、输入、交易日历、方案及参考摘要检查通过，共享执行引擎未改。

随机指标、事件、段位及审核全部保存，完整随机路径只保留每组种子1和32，其余可按冻结输入/源码/种子复现。后续复现旧研究请另设输出路径，不覆盖冻结参考文件。

本轮方案是在观察前一轮阶段差异后提出，不是未触碰的独立外样本；基金池有存续偏差、相互重叠、真实历史费用及净值发布时间/分红权益与支付日未全部核实。不是ETF或可兑现收益证明。10%过去波动不是未来回撤保证或用户批准的回撤目标。

下一步不继续盲目收紧市场门槛：检验实际持仓、资金修复及风险余量如何影响增配预算，特别是避免增配高波动股票时连带削减原来有效的核心配置；同时保留初始日期和状态敏感性检验。目标仍是形成可验证的投资方法，而不是挑出某一行较好的历史数字。
