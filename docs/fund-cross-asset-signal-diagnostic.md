# 跨资产信号诊断：评分、实际收益与风险单位

更新：2026-10-13。持续研究目标仍未完成。本轮发现一个重要的目标错位：标准化走势强度不是预期实际收益；即使它与未来单位风险收益相关，也必须与不看趋势的低波动对照比较。没有据诊断反向买低分，也没有修改线上排名或执行投资。

## 1. 本轮如何检查

沿用[跨资产组合回测](fund-cross-asset-trend-research.md)的冻结基金、股票/黄金/债券分类、252交易日预热及修正研究日历。四个历史池均截至2026-10-12，现代池从2024-07-29开始。

每个20/60/120交易日期限，以相同期限为信号日期步长；信号次日净值购买，持有该期限后赎回，普通买卖各0.1%，分红持现金。单基金净标签等于赎回净额加区间现金分红，除以含申购费的购买成本，再减一。股票/债券类的标签为类内各基金独立等金额购买后的收益均值，不是每日免费再平衡的代理，也不是持续投资账户收益。

同一期限的买入至卖出区间内部不重叠，可以在边界共用日期；资产类、历史池、期限及价格路径仍相关。536个日期-期限记录、1608个类-日期标签，**不是1608份独立验证**。每条记录同时保存过去信号和未来标签，未来标签仅用于回顾诊断，不用于当时决策。

观察三种开关，不据收益调阈值：21/63/252日收益至少两个为正、63日价格描述不是转弱/下行、最近已完成月末价格高于10个已完成月末价格的均值。

月度规则参考[作者对10个月均线的公开说明](https://mebfaber.com/2017/12/13/episode-86-quantitative-approach-tactical-asset-allocation/)。本轮是中国基金信号诊断，不复现原多资产策略，不采用原研究收益、现金利息或当日收盘无延迟成交假设。相同规则对所有资产类使用；严格高于的比较留1e-12相对容差，避免相等附近浮点噪声。

月底必须是研究日历中的实际交易月末。2026-10-12不是10月已完成月末，最后一个有效月末为9月30日；2026年2月月末为2月27日。至少10个完整月末才可用，缺失单独记录，不把缺失当下行或零收益。信号日在月中时只能使用最近已完成月末，不能将当日价格偷当未来月末价。

## 2. 高分是否对应更高实际收益

先检查每个信号日三个资产类的排序相关性，再对日期取均值。这里的相关性不是收益率、胜率、置信度或可交易超额收益；只有三个类，每日秩相关非常离散。

| 历史池 | 20日实际收益排序 | 60日实际收益排序 | 120日实际收益排序 |
| --- | ---: | ---: | ---: |
| 13主题+3债券 | -0.077（26日期） | -0.188（8） | -0.750（4） |
| 9主题+纯债 | +0.015（65） | +0.095（21） | -0.150（10） |
| 4主题+纯债 | +0.024（123） | 0.000（41） | -0.175（20） |
| 两宽基+黄金+纯债 | +0.072（146） | 0.000（48） | -0.042（24） |

尚未表现出稳定的高分高收益关系。现代120日只有4个日期，不能把负相关据为可靠反向预测，也不能把不同期限混成同一个样本。

## 3. 单位风险相关性可能被共同分母影响

现有分数是多个过去对数收益除以过去波动对应的周期标准差，再求均值；诊断的未来风险单位是未来扣费收益除以该信号日过去波动乘期限平方根。两者共享过去波动这一分母，相关性升高未必来自方向判断。

追加一个完全不使用趋势的对照：只按同日过去波动倒数排序。它也不是投资策略，更不能将其秩相关当投资收益。对照在初次诊断之后追加，透明保留此前版本，不声称事先独立验证。

| 60日标签 | 趋势分→风险单位秩相关 | 仅低波动→风险单位秩相关 | 日期配对增量均值 |
| --- | ---: | ---: | ---: |
| 13主题+3债券 | -0.125 | +0.063 | -0.188 |
| 9主题+纯债 | +0.357 | +0.452 | -0.095 |
| 4主题+纯债 | +0.427 | +0.427 | 0.000 |
| 两宽基+黄金+纯债 | +0.250 | +0.375 | -0.125 |

风险单位相关性高，不能直接当成趋势增量。较长池20日相对低波动对照有小的正增量约0.045—0.085，但60/120日不稳定，不足以支持显著升级。这里是对照诊断，不能证明全部相关性都由共同分母造成，也没有统计显著性结论。

另将评分乘其过去波动，取消评分内部的资产间波动分母，再与实际收益排序比较。现代20/60/120日相关性为+0.019/-0.250/-0.125；最长宽基池为+0.092/+0.063/+0.208。它改变了衡量对象，仍不是已校准预期收益，更不是一个已获得对应投资收益的策略。

下一轮可以明确检验这一个结构性纠正：收益排序和组合风险控制分开，保持原基金池、费用、执行和同样的10%预测波动预算。不能据最长池120日的局部改善跳过真实账户回测，也不能宣称该纠正已经成功。后续已完成[账户及宽基候选压力验证](fund-return-ranking-research.md)：宽基主曲线改善，但主题池及检查时点敏感性没有通过验证。

## 4. 关闭信号后的上涨解释了一部分退出代价

现代20日窗口，股票类至少2/3周期为正时，20个日期未来平均净标签+0.51%；关闭时6个日期平均+4.81%。月度均线开时22个日期平均+0.86%，关时4个日期+5.04%。这些是条件观察，不是因果效应，样本数量严重不对称。

例如2024-08-26、2024-09-25的股票类两种开关均关闭，后续20日净标签分别约+8.50%、+17.13%。另一关闭日期2024-07-29随后-3.82%。不能把这些未来事件作为提前可知的反转条件，或据两个上涨例子设计专门命中该日的规则。

现代60日月度均线关只有1个股票日期，随后+22.34%；开7个日期平均+2.77%。因此“开减关=-19.57个百分点”高度依赖一个窗口，不能解读为稳定反向机会。这与先前退出机制错过部分上涨的结果相容，但没有完整因果归因。

黄金的长历史月度开关较值得保留作风险管理候选：最长池60日开33次，平均标签+3.47%；关15次，平均+0.99%。然而2026年两个开启日期平均标签约-15.81%；2016年开3次平均+0.20%，关1次+2.15%，2022年开2次+0.25%，关2次+2.82%。不是所有年份同向，也不能忽略开启后的极端下跌。

因此本轮没有把月度均线直接部署成策略；也没有宣称它一定无效。若继续测试，须按真实月末检查、下一净值执行、资金到账及相同风险对照完整核算，而非把上述条件均值相加冒充组合收益。

## 5. 核验与局限

28项直接相关测试通过，其中8项新测试覆盖完整交易月末、10个月预热、未来代理价格不影响过去月度信号、未来价格改变标签而不改变过去信号、平价不算上行、未知状态独立、过早标签拒绝、日期/净值标签/NaN篡改拒绝，以及共同分母可产生高相关但零趋势增量的合成例子。

全部536条记录独立重建完成月末日期，从原始基金过去净值重建类信号、波动及月度均线；另用含费现金流重算单基金/类未来标签与归一化标签，再核对排序结果。核验通过，源码/输入/日历摘要与当前文件一致。初版至最终版的原有条件摘要和标签不变；最终新增的分母对照不改变原组合回测。

这里仍使用已看过的当前存续基金和回溯净值/分红版本；真实首次发布时间、现金分红支付日、逐产品申购费/赎回费及申购限制未完整验证。月度来源和对照是在研究中选择的，不是未查看样本。测试与独立计算核验不会消除研究选择偏差。

未找到显著、稳定、可投资的趋势收益提升，目标继续。没有将评分换名后作为成功，也没有用无趋势低波动配置替代用户要求的最终目标。
