# §3.1 界面验收与测试报告

- 日期：2026-09-13
- 范围：React 前端界面、演示数据展示与浏览器本地演示草稿。
- 环境：macOS、本地 Node.js 24.21.0、Google Chrome；Vitest / Testing Library、Playwright / Axe。
- 依据：[界面开发文档 §11.2](ui-interaction-design.md#112-可审查可验收的场景)。

## 1. 交付范围

四个业务入口与设置均可操作。已覆盖基金搜索／筛选／详情、净值与交易 K 线区分、披露及板块关联、三周期建议、个人决定、实际操作的演示录入、更正与撤销历史、费用规则录入、收益比较、策略采用与恢复、演示任务和 JSON 导入导出。

本轮是**界面层验收**，不是投资系统的真实业务验收：全部行情、建议、披露和收益曲线均为虚构样例；个人填写项仅作为当前浏览器的演示草稿。未实现的后端功能明确提示待接入，不用演示数据冒充真实计算结果，不执行交易或 AI 请求。

执行方式见 [README](../README.md#检查与测试)。测试代码与源码一并保存，便于后续接口接入时持续回归。

- 格式检查：`npm run format:check`。
- 类型与生产构建：`npm run build`，开启 TypeScript 严格模式。
- 单元／组件：`npm test`，检查查询模型、表单校验、保存与失败、关联、更正链、费用边界、比较模型、策略记录和嵌套 JSON 校验。
- 浏览器流程：`npm run test:e2e`，使用实际 Chrome 页面，检查跨页操作、刷新恢复、离开确认、布局、导入导出和自动无障碍规则。
- 视觉复核：实际查看基金列表、建议和收益页面的桌面／窄屏截图；1440、768、390 px 回归检查七条主要路由不发生整页横向溢出。宽表格保留自身滚动。

Playwright 的 HTML 报告位于 `frontend/playwright-report/`；截图、失败轨迹和无障碍检查附件位于 `frontend/test-results/`。这些是可重新生成的本地测试产物，不提交到源码库。Axe 自动检查通过不等于完整无障碍认证；本轮未覆盖所有屏幕阅读器、Safari／Firefox 和实际浏览器缩放组合。

## 4. 测试中修复的问题

- 宽表格隐藏表头造成的窄屏整页横向溢出，修正其定位范围。
- 辅助文字与背景对比度不足、提示中的链接视觉区分不足。
- 设置页 JSX 加载错误，并通过严格类型检查及浏览器加载回归。
- 草稿保存被浏览器拒绝时不得提前显示成功；失败场景保留输入。
- 导入校验覆盖嵌套对象、重复标识、缺失引用及更正链循环／分叉，失败不替换现有记录。
- 弹窗内浏览器后退和跨页链接增加草稿保护；多个脏表单共用一个离开守卫，关闭弹窗后底层草稿仍受保护；保存成功后的详情跳转不误拦截。
- 基金库直接展示 ETF 模拟 K 线，并与场内基金详情复用。新增 14 项模型测试验证 OHLC 边界、固定报价一致性、成交量及尾随均线；新增 5 项浏览器测试验证实际 SVG 蜡烛绘制、基金／范围切换、均线显隐、行情提示、缩放／重置和三种宽度。仅净值基金仍使用净值曲线。

## 5. 运行限制

- 不要录入真实投资资料或密钥。清除浏览器站点数据会清除演示草稿；演示导出不是正式业务备份。
- 本轮浏览器测试面向 Vite 开发服务器，另单独验证生产构建；后端托管、深层路由回退及发布运行需在 §3.6 集成测试。
- ECharts 的按需加载图表包仍触发构建体积提示（约 627 kB，gzip 约 212 kB），未隐藏警告或放宽阈值。页面已按业务拆包；后续结合真实数据规模评估图表首开耗时及进一步拆分。
