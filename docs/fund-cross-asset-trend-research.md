# 跨资产趋势：收益、对照与执行验证

账户更正：下列冻结收益可能受完整退出残余及额外检查影响，重算前不作为当前已核验收益，见[完整退出状态更正](fund-full-exit-precision-correction.md)。

后续已完成[收益排序纠正及宽基候选压力验证](fund-return-ranking-research.md)。本页保留原11规则的冻结结果，不将后来规则的局部高收益覆盖到旧表。

更新：2026-10-13。目标仍进行中，尚未找到能把趋势评分显著、稳定升级为投资策略的证据。本轮不再只在股票主题间排名，而是检验股票、黄金、债券的大类趋势。高收益不能自动归因于趋势，固定黄金预算和无趋势风险配置必须同时对照。

## 1. 方法和边界

参考[AQR的趋势研究](https://www.aqr.com/insights/research/journal-article/a-century-of-evidence-on-trend-following-investing)提出大类时间序列动量这一研究方向。原研究包含衍生品多空交易；本轮仅用本地已冻结的中国基金净值，不能做空、不加杠杆，不能声称复现其收益或证明其结论在这三个资产类别成立。

每类内部用基金每日简单收益的等权平均构造信号序列。它只是观察趋势的代理，不是可无成本每日再平衡的账户。真实账户逐只基金记录份额、现金、待确认及待到账金额，收益来自实际净值和有费用的交易。

信息只使用信号当日及以前的历史：21/63/252交易日对数收益，以其中正收益的比例作为趋势投票；相对排序取各周期收益除以过去60日波动对应的周期标准差，再求均值。年度波动下限为股票/黄金5%、债券0.5%，不是预计未来至少有这些波动。

全部账户至少预热252个交易日。同池各方案同起点，但不同历史池起点不同。现代池因此从2024-07-29开始，**不能把本轮收益与此前2024-01-09开始的120日预热报告直接相减**。

每20交易日检查，绝对3个百分点、相对目标25%的交易容差。信号决定预算/份额，下一交易日净值执行，T+1确认、T+2到账，待到账赎回款不能提前再用。现金利息为零。

普通买卖各0.1%是研究情景，不是已逐产品核实的费率；不足7个确认自然日赎回至少1.5%，普通交易尽量等待7日，风险退出可提前但仍扣费。末日赎回扣费。另测普通买卖各0.5%/1%、检查相位5/10/15及延迟至T+2执行。申购限额、完整分红支付时点、净值首次发布时间及产品历史费用仍有假设。

除明确标注的旧参照外，提议权重按过去60日真实基金收益协方差整体缩小，预测年化波动不超过10%，剩余留现金。债券也一起缩小，不是无风险现金。**10%是历史预测约束，不是未来波动或最大回撤保证**。旧参照的风险削减转入债券，仅用于连续性比较，不能把两种风险处理的差异认作趋势收益。

## 2. 限定的规则与对照

第一轮在运行新收益前限定10个方案，不事后删除失败规则：

| 方案 | 提议预算或趋势作用 |
| --- | --- |
| 旧40%股票参照 | 股票40%、黄金20%、其余债券，沿用旧风险转债券机制；本轮同样20日检查 |
| 固定40%股票 | 股票40%、黄金20%、债券40% |
| 三类等额 | 每类1/3 |
| 固定保守 | 股票20%、黄金20%、债券60% |
| 固定黄金60% | 股票20%、黄金60%、债券20% |
| 固定股票60% | 股票60%、黄金20%、债券20% |
| 无趋势逆波动 | 按各类过去60日波动倒数分配，单类不超过60% |
| 趋势投票预算 | 各类1/3乘自身正收益投票；其余现金，不重新填满 |
| 趋势逆波动 | 投票/波动比例分配，单类不超过60%；零票排除 |
| 双动量领先类 | 股票/黄金至少2/3票才有资格，相对标准化分最高者提议60%；债券至少2/3票才分40%。无风险类合格时，债券合格则60%，否则现金 |

固定预算仍受共同风险缩放，不代表每日维持名义仓位。只有一个逆波动候选时最多60%，不足部分现金。股票类内部等权，不能事后用该池最赚钱的股票主题代替类信号。

初轮结果后只追加一个明确的后续规则：双动量领先类若63日价格描述为“转弱”或“下行”则不参与股票/黄金选择，债券原投票条件不变。这是已看过历史后的修正，不是事先独立验证，也不是阈值搜索。

## 4. 延长历史后的检查

共同截止2026-10-12，各行的基金池、起点、股票类含义不同，不能反选赢家拼接。表中每格为累计收益/最大回撤。

| 历史池及起点 | 无趋势逆波动 | 固定黄金60% | 双动量领先类 |
| --- | --- | --- | --- |
| 9主题+纯债，2021-05-11 | +46.05% / -5.95% | +89.16% / -11.25% | +80.37% / -10.80% |
| 4主题+纯债，2016-07-21 | +70.75% / -5.63% | +134.15% / -12.31% | +76.84% / -13.75% |
| 沪深300/中证500/黄金/纯债，2014-09-19 | +123.15% / -6.29% | +179.70% / -11.89% | +200.05% / -18.96% |

最长宽基池的双动量高于固定黄金预算约20.35个百分点，但回撤大约7.08个百分点；其他池并不一致获益。更长历史的正收益不是现代主题池可事先获得的收益。

趋势逆波动在四个主账户中均低于不加趋势的逆波动收益，且回撤更大。本轮不能证明趋势投票给风险配置带来增量。

9主题池转弱退出后收益/回撤为+56.76%/-10.10%，4主题池为+63.89%/-10.94%；最长宽基池为+116.36%/-14.56%。减少了一些下跌，也损失大量后续上涨，尚无一致的经济改善。

年度重新开户检验不是连续账户分年收益，不可相加。例如9主题池原双动量2022年-6.43%、固定黄金预算+2.24%；旧4主题池原双动量2021年-7.73%。近期上涨并未覆盖所有入场阶段。

## 6. 核验、限制及下一步

修正后的117项相关研究测试通过，包含未来数据不影响过去、预热要求、信号日期一致、无杠杆和权重上限、独立重建信号/风险、篡改拒绝、局部状态不依赖长期累计序列的归一化原点。未改线上排名、数据库或执行交易，未提交代码。

修正前一次全库检查680项，其中3项断言失败位于未改动的关联行情/板块财务模块，另6项本地HTTP服务测试因沙箱禁止绑定端口报错；因此不能宣称全库通过。本轮没有修改这些模块来掩盖失败。

初版10规则完整报告保留。增加近期状态后，独立审核曾在2015-04-09/10黄金发现“震荡/修复”标签差异：长期累积代理与局部重建的极小浮点差异跨过严格分类阈值。该次完整运行因审核失败停止，未输出成功报告；没有跳过审核。最终近期状态从原始63日基金简单收益以固定原点1重建，原收益、投票、排序及退出阈值不变。这两个标签本身均不触发转弱退出。

最终851个账户（包括主要、重新开户年度、各期限窗口、压力和连续性参照）全部通过独立账本重放及逐决策信号/风险重建；17份源码、协议、两份基金输入及修正日历的摘要与当前文件匹配。原10规则40个主账户的指标与初版完全一致。账本核验不是收益有效性或投资适当性的保证。

所有历史已被反复查看，当前存续基金池可能有幸存者偏差，净值和分红是回溯取得的版本。多个方案、年度和窗口不是多个独立实盘证据。即使账本及时间使用核验通过，也不能消除这些研究选择偏差。

目标仍未完成。下一步应先诊断跨资产信号在不同市场阶段的方向判断是否稳定、误退出和资金闲置各损失多少，再限定新的可检验假设；不能只根据历史最好收益持续微调门槛。随后完成的[信号和共同分母诊断](fund-cross-asset-signal-diagnostic.md)发现，较高单位风险相关性未稳定胜过无趋势低波动对照，需进一步分开检验收益排序与风险约束。估值资料不全的路径保留，详见[主题估值研究](fund-theme-value-research.md)，不以等待估值资料作为停止其他研究的理由。
