# 板块策略优化：参数、数据与买卖规则

日期：2026-10-12。方案已实现为实验策略模块和冻结参数文件，尚未替换网页排名或接入实际交易。

2026-10-13 补充：本文的 +21.37% 是板块指数代理结果，未包含不足7天的基金赎回费，不能用于估算实际基金投资收益。加入确认日、赎回到账等待，并扩充真实基金净值后的结果见[基金手续费与扩展回测](fund-rotation-fee-research.md)。原规则在13主题基金共同区间仅 +0.08%，不要把下文旧结果作为基金收益结论。

## 1. 结果

在本地 86 个行业的共同历史区间，改进方案的假设资金账户收益为 **+21.37%**，本金 10 万元变为 **121,369.98 元**，每日账户最大回撤 **-11.95%**。买入和卖出分别按 0.1% 计费，累计费用 2,636.57 元。

账户起点为 2025-07-04，首次执行为 2025-07-07，结束于 2026-10-09。本轮加入沪深300行情，而该系列在本地只到 10 月 9 日，因此所有本轮对照同步截止到该日，不填补 10 月 12 日数据。前一次报告截止到 10 月 12 日的收益不能直接用于本轮比较。

| 同期方案 | 累计收益 | 最大回撤 |
| --- | --- | --- |
| 原短期趋势分前十、20 日全量换仓 | -13.69% | -28.85% |
| 原短期状态筛选、每个候选配置 10% | +10.50% | -10.20% |
| 全行业等权、20 日换仓 | +9.74% | -22.68% |
| 沪深300买入持有，买卖各 0.1% | +8.66% | -14.81% |
| 改进策略：灵活持有、转弱退出、大盘风控 | **+21.37%** | **-11.95%** |

结果是经过历史筛选后的板块指数模拟，具有选择偏差。它满足本次共同历史区间内的正收益目标，不能证明未来收益，也不能直接当作实际基金或 ETF 收益。

## 2. 从三个方向排查

### 参数影响存在，单靠参数没有解决问题

保留旧的 20 日换仓与状态规则，仅修改同组收益权重为 10/20/30、入场门槛为 55/60/65，分别观察短中长期，共 27 个配置。

短期事后最好结果为 +13.04%，对照为 +10.50%；中期配置最高约 +2.95%，最低约 -2.59%。参数可以改善局部收益，但不能解释或修复所有周期的表现。

新策略另外比较了短期/综合/长期分数、5/10 日检查频率，以及 5/8/10 个持仓、8%/10%/12% 移动止损等。提高集中度未提升本轮合格方案的最好收益：5 个持仓的收益约 11.67% 至 12.62%，部分配置回撤超过 15%；最终仍选择 10 个持仓。

### 有数据没有用，也有历史上不能使用的数据

本地 86 个行业共 36,722 条行情，开高低收、成交量与成交额均有正数值，开收价均位于高低价范围内。价格数据不足不是本次回测失效的主要限制。

此前未使用沪深300的市场方向和成交量确认，本轮分别加入对照：

| 规则变化，其他主要条件相同 | 累计收益 |
| --- | --- |
| 5 日检查、每日退出、10% 移动止损 | +17.72% |
| 上述方案加量能入场门槛 | +17.74% |
| 上述方案仅在沪深300高于60日均线时买入 | +13.30% |
| 同时在沪深300不高于60日均线时退出持仓 | **+21.37%** |

成交量在这一段历史没有带来明显增量；不能据此认定它在所有市场无用。大盘信息的使用方式更重要，仅限制买入不足以控制已经持有的风险。

财务与估值观察最早记录于 2026-09-19，缺少覆盖 2025 年至 2026 年上半年的首次可见资料。不能把今天的估值、财报或成分信息回填到当时的信号。实际可买基金与 86 个行业的完整映射、历史成分股宽度和资金流口径也未在本次实验中补齐。

### 固定换仓与退出规则是重要因素

以下对照使用相同的综合评分和入场规则：

| 买卖规则 | 累计收益 |
| --- | --- |
| 保留持仓，但每20日才检查分数退出 | -10.42% |
| 每日检查分数退出，仍每20日检查买入 | -1.88% |
| 加入均线转弱退出，仍每20日检查买入 | -1.16% |
| 每5日检查买入，保持每日退出 | +15.59% |
| 再加10%移动止损 | +17.72% |

只把“定时清仓”改成“继续持有”并不够；退出响应、买入检查频率与市场风控需要一起设计。上述为特定样本中的对照结果，不是对因果关系普遍有效的证明。

## 3. 冻结后的新规则

综合分直接复用已有趋势分，按 `50%短期 + 30%中期 + 20%长期` 组合，未额外拟合未知收益。

买入条件：综合分至少 60、价格高于20日均线、最近5日变化为正、沪深300高于60日均线。每5个交易日检查一次，从符合条件的行业里按综合分排序补充空余持仓，最多10个。

新买入预算以信号日账户资产的10%为上限，并受剩余现金和整体风险预算限制。持有期间权重随价格漂移，不为了维持等权每天再平衡。合格旧持仓继续保留，不因名次轻微改变反复买卖；候选不足时留现金，现金不计息。

每日检查以下任一退出条件：

- 综合分低于45，给入场和退出留出区间，减少门槛附近反复交易。
- 价格低于20日均线，且最近5日变化为负。
- 自买入以来的最高收盘价回落至少10%。
- 沪深300回到60日均线或其下方。

退出后同一行业冷却10个交易日。所有信号在收盘后产生，下一交易日收盘价执行。移动止损只触发后续卖出指令，不假设能按止损价成交；市场跳空和下一日继续下跌仍会影响账户。最后一天按收盘价退出并计卖出费用。

本轮没有采用量能门槛、波动缩仓或增加卖出确认天数，因为它们在各项历史对照中没有共同优于当前方案。它们的结果仍完整保留。

## 4. 收益与稳健性

| 检查 | 收益 | 最大回撤 |
| --- | --- | --- |
| 不计交易成本 | +24.26% | -11.26% |
| 买卖各0.1%，主要结果 | **+21.37%** | **-11.95%** |
| 买卖各0.5% | +10.48% | -15.64% |
| 2026年重新开户模拟，起点2025-12-31 | +12.12% | -8.22% |
| 2026上半年独立模拟 | +14.96% | -7.57% |
| 2026下半年独立模拟，截至10月9日 | **-2.78%** | -2.78% |

持续账户的2025部分年度收益为 +2.22%，2026截至10月9日为 +18.74%。它与2026重新开户的 +12.12% 不同，因为原账户保留了2025年买入的持仓。独立分段结果也不能直接相乘作为持续账户收益。

将5日检查周期的起点平移0/1/2/3/4个交易日，保持共同资金起点、等待期间持现金，结果分别为 +21.37%、+9.28%、+14.71%、+25.20%、+14.90%。均为正，但范围仍很大；没有挑出 +25.20% 的日期作为默认起点。

## 5. 选择过程与过拟合限制

本轮记录43个买卖/数据/仓位配置和27个旧规则参数配置，共70个配置，另保留原策略与宽基对照。此前多轮也查看过这段行情；70不是“首次且独立试验”的数量。

第一次单用2025训练收益选择“只保留持仓”的规则，后来亏损约10.4%；加上每日退出与检查频率约束后，训练期选择波动缩仓版本，但2026重新开户收益约 -0.39%。这些失败结果没有删除。

最终选择明确使用历史验证结果：在每日退出、检查间隔不超过10日、移动止损已启用的配置中，要求2025训练期、2026重新开户和全区间都为正，全区间回撤不超过15%，然后比较全区间收益。因此 **+21.37% 是事后筛选收益，不是严格样本外收益**。最终成本和起点检查仍保持正收益，但不能消除选择偏差。

价格路径、自身方向与横截面排名分开使用，参考了[时间序列动量研究](https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum)的概念区别；其跨资产研究结果不能直接当作本项目的A股行业有效性证据。多次回测选择最好结果的风险可参见作者原文[回测过拟合概率](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。本项目没有声称计算出该论文的过拟合概率或统计显著性。

固定本次参数后，后续应记录新行情上的原始信号、实际可买产品及其成交/净值，再判断是否值得用于实际投资。当前仍存在亏损区间，也缺少实际产品的完整收益证据。

## 6. 实现与独立复算

- `backend/analysis/sector_rotation.py`：持仓保留、分离入退场门槛、冷却、次日执行、移动止损和市场退出。
- `config/sector-rotation-experiment-v1.json`：冻结策略；标记为历史筛选的实验配置。
- `scripts/optimize_sector_rotation.py`：全配置对照、训练期失败记录、参数与数据实验、成本与起点检查。
- `scripts/backtest_sector_rotation.py`：只运行冻结参数，不重新优化参数。
- `scripts/validate_sector_rotation.py`：从原日线和逐笔交易独立重建现金、份额、费用、资产和回撤；校验次日执行、完整日期网格、终末清仓，以及输入和代码摘要。

30项相关自动测试通过，包括初始与最终费用、保留持仓、止损延迟成交、退出确认、冷却、现金约束、状态/市场门槛、未来数据隔离，以及被篡改的交易/资产/日期会被验证器拒绝。

本地结果文件保存每次交易、每日资产、候选决策、行情摘要和代码摘要，不修改日常数据库。

```bash
.venv/bin/python -m unittest discover -s tests -p 'test_sector_rotation.py'
.venv/bin/python -m unittest discover -s tests -p 'test_sector_trend*.py'
.venv/bin/python -m scripts.optimize_sector_rotation
.venv/bin/python -m scripts.backtest_sector_rotation
.venv/bin/python -m scripts.validate_sector_rotation
.venv/bin/python -m scripts.validate_sector_rotation \
  --report runtime/verification/sector-rotation-frozen-backtest.json \
  --output runtime/verification/sector-rotation-frozen-ledger-validation.json
```

优化结果：`runtime/verification/sector-rotation-optimization.json`。冻结参数结果：`runtime/verification/sector-rotation-frozen-backtest.json`。独立核验结果：`runtime/verification/sector-rotation-ledger-validation.json` 和 `runtime/verification/sector-rotation-frozen-ledger-validation.json`。
