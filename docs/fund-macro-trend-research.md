## 1. 本轮新增真实信息

从[央行LPR原始公告列表](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/125440/3876551/index.html)按公开分页链接取得2019-08至2026-09的86个月公告。92个原始页面含86份公告与6个列表页，保存内容摘要和采集时间，完整月份检查通过。

正文与标题日期、1年期和5年期以上报价、页面显示的发布时间分别解析并核对。2023年部分正文有空格，2024年7月列表标题有省略号：按正文规范化空格、完整链接标题修正采集，不用相邻月份填补。研究报告重新读取原始页面核对报价，不只信任整理后的数值。

2019-08-20为改革后的机制起点，不能与之前的报价直接拼接，依据[央行机制说明](https://www.pbc.gov.cn/en/3688229/3688335/3730276/3883798/19e15ae1-4.html)。LPR是银行贷款参考报价，不是股票估值、国债收益率或债券基金收益；企业实际融资成本也并不等于LPR。

[2024年7月原始通知](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/125440/3876551/5410019/index.html)同时调整发布时间。计算不假定所有年月均在同一个钟点发布，而使用各页显示的时间，并延迟到下一自然日后才允许进入信号。

**可见性仍有限制：**这是今天获取的原始公告页面与页面标注的过去发布时间，不是当时保存的网页快照。本批页面标注日期均未晚于公告日期，但不证明首发时间及内容从未被修订。因此结果只是按显示时间加滞后的条件回测，不宣称完整点时数据。另测试7和30自然日的信息滞后；滞后不是独立验证样本。

## 2. 在看到本轮收益前限定的规则

90自然日前后，分别只取当时已经可见的最新一期公告，将1年期和5年期以上报价简单平均。如果当前均值低于90日前均值，记为近期降息。这是研究定义的组合指标，不是央行发布的复合利率或经济冲击估计；不插值，不把未来公告倒填到过去。

在相同股债金框架里比较五个初始规则：

| 规则 | 波动控制前的股票提议预算 |
| --- | --- |
| 基础配置 | 固定40% |
| 原价格趋势质量预算 | 35% + 25%乘60/120日平均回归方向与拟合度 |
| 降息加仓 | 近期降息时50%，其他40% |
| 降息且趋势确认 | 近期降息且价格趋势质量为正时50%，其他40% |
| 降息但趋势转弱 | 近期降息且价格趋势质量为负时30%，其他40% |

黄金提议20%，剩余等权配置同池债券；单债券上限90%，不能分配的部分留现金。全部方案使用过去60个交易日的协方差及相同10%预测年化波动约束，不是10%回撤保证。风险约束可能再缩减股票和黄金，实际持仓也会因净值变化、调仓容差和资金等待偏离目标。

每10交易日检查，绝对偏差带3个百分点与目标金额25%的相对带取较小者。普通买卖各0.1%为费用情景；不足7个确认自然日赎回至少1.5%，确认T+1、到账T+2。风险退出仍收费；终末赎回也收费。

基金指标预热120日，利率需要过去90自然日信息；所有规则在同池使用共同起点。旧4主题和宽基四资产从2019-11-19开始，不能与前轮2014或2016起的累计收益直接比较。

五规则首次结果后，另加固定50%和30%股票预算的同控制参照，检验收益是否仅来自增加或减少股票。两版完整报告都保留。规则限定不是公开时间戳的独立预注册，底层基金历史也早已用于其他实验。

## 3. 完整主题池结果

13主题加3债券，共同区间2024-01-09至2026-10-12，初始10万元、现金不计息、终末赎回。以下均为按上述情景扣费后的累计收益，不是年化或实盘。

| 规则 | 累计收益 | 最大回撤 |
| --- | ---: | ---: |
| 固定40%股票加波动控制 | +34.95% | -8.88% |
| 固定50%股票加同样控制 | +35.20% | -9.00% |
| 固定30%股票加同样控制 | +30.70% | -8.27% |
| 原价格趋势质量预算 | +32.91% | -8.74% |
| 近期降息加仓 | **+35.55%** | **-9.17%** |
| 降息且价格趋势确认 | +34.96% | -9.16% |
| 降息但趋势转弱时减仓 | +31.37% | -8.97% |

降息加仓约为10万元变135,551元，比固定40%提议方案多约604元，比固定50%多约352元，回撤更大。**这不是“极大程度提升”的证据。价格趋势确认在现代池并没有额外增益。**

不同信息滞后下，降息加仓为35.55%（1日）、35.93%（7日）、36.50%（30日）；不能反过来挑30日当最优发布滞后。调仓相位5的降息方案39.60%，固定50%参照40.24%，再次表明没有一致择时优势。

普通买卖各0.5%时，降息加仓33.09%、基础40%为32.96%；各1%时分别30.04%、30.34%。费用提高后，相对基础40%的微小优势可消失。固定50%在这两种情景为32.55%、29.33%。

2026首交易日重新开户、截至10月12日，基础40%和三个利率覆盖规则均约-3.25%；完整历史正收益不表示任意入场时点都盈利。年度重新开户与连续账户不是同一个资金路径，不把年度收益直接相加。

## 5. 短中长期窗口

完整主题池，20/60/120交易日分别重新以10万元开户；期限末全部赎回。已知期限内距终末赎回不足7确认自然日不再新买。相邻窗口不重叠持仓区间，但指标和宏观环境共享，不能当成独立政策事件。

| 期限 | 窗口数 | 基础40%平均收益 | 降息加仓平均收益 | 两者盈利窗口比例 | 降息方案最差窗口 |

## 6. 验证与下一步

88项不重复的相关测试通过。新增检查包括公告正文/标题/发布时间、空格和组合标题、自然日信息滞后、未来公告不改变过去信号、晚发布旧公告不覆盖较新公告、原风险控制保持、无历史回退基础配置、日期/数值篡改拒绝。

初版445个账户、加入仓位参照版623个账户分别逐笔重建现金、应收款、FIFO份额、费用和每日资产；另逐决策从原始公告重建信息可见性与利率状态，从过去净值收益重建预测风险。所有检查通过，源码与协议摘要匹配。两个实验大量重复，不是1068个独立投资样本；核账通过也不证明投资有效。

86个月中仅14次报价组合发生变化，都是下降；现代主题共同账户内只有4次。这不足以证明加息、完整经济周期或独立政策冲击下的泛化。多只基金面对同一个降息不能算多次独立事件。

现代主题结果目前仍主要来自资产分散和波动控制，LPR不能独立解决趋势评分到投资策略之间的缺口。下一轮优先核查能刻画估值或经营状况的原始发布数据，必须分清报告期、首次发布时间、修订版本与今天的采集时间。当前本地成分财务样本属于近期观察，不默认将今日成分及修订数据回填历史。
