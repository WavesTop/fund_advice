## 2. 实际取得了什么

医药、银行、证券保险分别取得3537、3232、2850行原始年度查询记录，其中空估值7、450、0行。数据不插值、不将空值当零。分别核对官网链接的[医药单张](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000814factsheet.pdf)、[银行单张](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/399986factsheet.pdf)、[证券保险单张](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/H30588factsheet.pdf)：2026-09-30滚动市盈率23.49、7.20、7.67，均与接口 `peg` 字段同日读数一致。三张单页均渲染检查了代码、发布日期、报表日期及字段位置。

这是候选滚动估值的同日正值核对，不是全历史计算方法或首次发布版本的证明。没有将今日成分股、财报或全历史分位回填过去，也不能把此接口字段解读成通常的PE/增长率。计算用股本、亏损处理、历次方法变更及发布时点仍需进一步查证。

军工已缓存2013—2020年1718行，随后历史采集收到HTTP403。由于原异常没有保存响应正文及标头，拒绝原因未确认；失败年份/URL只依据已完成年度和顺序程序推断，明确记录为推断，不假称取得服务器授权说明。军工缺少2026同日历史值，暂不通过字段核对。传媒取得公开单张、未取得历史；其余主题资料仍缺。

尊重停止记录后，后续历史整理只读现有缓存，不换身份、拆分被拒绝的区间或改路径绕过拒绝。缺失记录逐主题保存。还检查了本地只读数据库：与中证历史接口对应的原始资产仅见一个其他指数的近期估值转录，不能充作这些主题的完整原始历史；价量或净值投影也不能恢复被丢弃的PE。

未购买数据、登录数据服务、联系供应商或改权限。已向用户询问是否有可合法研究的历史文件或已授权服务；未答复不影响使用现有数据的诊断，但不能补造另外九个主题的估值。

## 3. 保持组合不变，只检验信息价值

全部规则提议40%股票基金、20%黄金、40%债券，再使用同样的过去60交易日协方差、10%预测波动约束。不是10%未来回撤保证。基金真实净值计算盈亏，现金不计息；普通买卖各0.1%为情景，不足7确认自然日赎回至少1.5%，T+1确认、T+2到账、末日赎回扣费。

每10交易日检查，相同绝对3个百分点/目标金额25%的容差。单主题股票部分权重不超过2/N，N是该账户实际股票主题数，不将几个可得数据的主题自动满仓。未知主题始终占股票部分中性1/N；已知K个主题只在原来合计K/N的预算内调整。整体风险缩放会共同调整股票、黄金，未知主题也不例外。

每个主题只与自身历史估值比较，不直接认为银行PE低于医药就更便宜。沿用报价滞后1交易日、最多额外陈旧3日、最多1260个过去市场交易日、至少252个正值、有效覆盖至少95%、当前报价排除于参照、同值中位秩的分位计算。另测2/5日信息滞后。

价格质量是60/120日对数价格回归的方向乘拟合度均值，范围-1至1，不是未来上涨概率。六个方案在本轮收益计算前限定：

| 方案 | 调整股票主题的规则 |
| --- | --- |
| 等权基础 | 1/N |
| 全主题价格趋势 | 全主题乘数1+0.5乘价格质量 |
| 同覆盖价格趋势 | 仅估值当日已具备参照的主题使用价格乘数，其他中性 |
| 自身估值 | 已知主题乘数1.5减自身分位 |
| 估值/趋势混合 | 已知主题乘数1+0.25乘价格质量+0.5乘(0.5减分位) |
| 估值且趋势确认 | 已知主题分位不高于20%且质量正时乘1.5；分位不低于80%且质量负时乘0.5；其他乘1 |

各乘数在已知子组内按比例分配并限制集中度。“同覆盖价格趋势”参照专门检查估值是否比同样三个主题的价格信息更有用，而不是仅因覆盖范围改变而得益。

原风险引擎默认等权行为不变；基础参照走原始等权计算路径，避免乘法/除法的极小浮点差异导致对照金额尾差。完整主要账户以及20/60/120日基础窗口与前轮修正日历报告的指标完全一致。

## 4. 完整基金池、部分估值覆盖的结果

13主题加3债券，2024-01-09至2026-10-12，10万元起始。表内为上述费用情景后的累计收益，不是年化或实盘；13主题中有12个股票主题及1个黄金，实际估值信号只覆盖3个股票主题。

| 方案 | 累计收益 | 最大回撤 |
| --- | ---: | ---: |
| 等权基础加波动控制 | +34.95% | -8.88% |
| 全主题价格趋势倾斜 | +34.12% | -9.23% |
| 同覆盖价格趋势倾斜 | +34.61% | -9.00% |
| 自身估值倾斜 | +33.92% | -9.01% |
| 估值/趋势混合 | +34.27% | -9.12% |
| 估值且趋势确认 | +35.02% | -9.18% |

确认方案约为10万元变135,020元，基础134,947元，**累计只多约73元，回撤更大约0.30个百分点**。其203笔买卖、情景费用501.17元，基础175笔、459.66元。并非明显改善。

同覆盖价格参照为34.61%，确认方案多约0.42个百分点，但代价是更大回撤；不足以证明估值产生稳定超额收益。这里不能推断完整12主题估值方案一定无效，也不能据三个主题的局部结果认定完整方案有效。

## 6. 核验和尚未完成的目标

107项相关测试通过。新增覆盖未知主题保持中性、已知组预算不挤占未知组、单一已知主题不集中、覆盖匹配对照、集中度上限、共享波动约束、定制权重校验、发布前数据拒绝、未来估值不影响过去信号，以及现金/日期/权重篡改拒绝。还测试缓存模式绝不发送新网络请求，证券保险指数不能替换成名称近似指数。

最终492个账户逐笔重建现金、应收、FIFO份额、确认日与费用；逐决策从原始可见历史重建分位，从基金过去价格独立重算方向与拟合度，再通过独立的有界比例求解核对组合权重和未知主题预算，从过去收益重建预测风险。全部通过，源码/协议摘要匹配。

初版和最终版保留，主动规则主要账户指标完全相同；最终仅让基础参照保持原始等权数值路径。反复核验同一历史，不是独立实盘样本。

目标仍进行中。关键缺口包括9个主题的完整可核历史、基金基准沿革、完整估值方法和修订版本、逐产品费用及申购限制、未查看的独立验证。当前来源覆盖和字段核对发生在今天，本身也可能形成回溯选择偏差，任何部分样本正收益都不能替代这些证据。

接下来不据这次微小收益调阈值去追逐最好历史。完整估值方向保留待可靠数据补齐；同时仍可使用已核基金净值研究跨资产趋势及风险分配等其他路径，持续目标不缩为只验证这三个主题。新一轮结果见[跨资产趋势研究](fund-cross-asset-trend-research.md)。没有改线上排名、执行交易或提交代码。
