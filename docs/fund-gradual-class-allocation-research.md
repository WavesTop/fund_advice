# 保留持仓、渐进调整与趋势投资

更新：2026-10-14；净值截至2026-10-12。接续[趋势收益预测研究](fund-class-return-forecast-research.md)。本轮不新增预测因子，而是直接检验投资动作：不换仓是否应成为合法选项，调整仓位能否分步完成，以及小步调整是否被交易门槛一直忽略。

**结论：执行方式有局部改善，但趋势预测的投资优势仍未成立。** 13主题5日趋势方案从立即切换的+27.69%/回撤11.57%，变为累积调整的+31.83%/回撤7.53%；同条件均值对照+32.80%/回撤8.40%，不择趋势的分散对照+42.72%/回撤9.26%。较长历史池没有出现同样收益改善，不能按基金池或年份事后选择动作。

## 1. 四种动作，预测不变

沿用上一轮两类模型：三项类身份的收缩均值对照，以及加入价格趋势特征的13项岭回归。成熟60日实际持有毛收益标签、1096日窗口、至少24个成熟观察日期、惩罚1，以及未拟合前沿用原单赢家，全部不变。均值对照仍有当前绝对趋势准入，不能称完全无趋势策略。

| 动作 | 目标如何形成 | 本轮用途 |
| --- | --- | --- |
| 立即切换 | 在既有候选中选最高资金收益估计，提交完整目标 | 重跑对照 |
| 保留持仓选项 | 加入实际持仓候选，与完整调整候选比较 | 验证不交易是否有帮助 |
| 从实际持仓小步调整 | 每次从当前实际权重向候选目标移动一部分 | v1，保留已发现的门槛限制 |
| 累积目标的小步调整 | 从上一次已选择目标继续推进，未成交部分不自动丢失 | v2，检验门槛问题后的经济结果 |

移动比例为`min(1,距上次实际决策的交易日数/60)`，首次决策取1。20日常规检查约移动1/3，5日约1/12，到账后的额外检查只用实际已过时间；不是每次回调再按名义20/5日推进。这个60日尺度是预先固定的执行启发，不是估计出的趋势衰减，也不保证60日内完全换仓或强制持有60日。

每个候选仍按风险缩减后的基金资金权重预测毛收益，扣普通费率乘实际持仓到候选目标的绝对权重换手。该估计没有精确预测短持费、到账、现金不足和终端费用；真实账户逐笔核算这些约束。保留持仓意味着保留基金间实际漂移比例，不强制重置为类内等权或60/40。

当前类趋势失效的份额先移除，已有持仓与旧计划均用当时过去协方差约束到10%预测年波动，再做渐进动作。不用旧目标延缓绝对趋势退出；当前实际风险超限减仓仍执行原有紧急规则。不交易选项是安全处理后的实际持仓，不是无条件拒绝风险退出。

账户继续使用FIFO、下一净值成交、T+1确认、T+2到账、普通每边0.1%、不足7确认自然日赎回费下限1.5%、普通7日等待、3个百分点/25%再平衡带、现金不计息，不做空、不加杠杆。不降低门槛，不提前消费赎回待到账款，不把目标计划当作已买到的份额。

## 2. 找到并补测执行停滞

v1从实际持仓重新起步，每次小步幅可能都在门槛内。例如20%股票权重，每5日向零移动1/12，目标每次仍是18.33%；差1.67个百分点，既不到3个百分点，也不到目标的25%。若不成交，下次再次从20%起步，而不是继续减至16.81%。目标不会自然跨过门槛。

在给定持续合格信号、固定预测和恒定净值的受控测试中，连续75个交易日想减股票但普通卖出为0，16次决策被门槛忽略。这个测试只检验计划和成交逻辑，手工给定信号不代表恒定净值真的产生这样的市场趋势，也不是历史收益证据。

v2将上次实际决策的目标作为下一次渐进起点，同时保留真正的实际持仓候选。每次检查重新过滤旧目标中已失效的类、重新计算风险；若选择不交易，计划也重置到安全实际持仓。测试确认目标会在下一次或随后检查跨过原门槛并执行普通减仓，现金/FIFO核验通过。篡改上一目标、使用未来计划、丢失前一决策目标或保留失效类均被拒绝。

v1不是账本算错，其结果仍有效，但不能当作能持续累积的调整策略。v1的13主题5日趋势收益+35.31%、回撤8.02%，v2为+31.83%、回撤7.53%。不能留下较高的旧收益，拿新的执行机制解释它；更有效地成交也不保证赚得更多。

## 4. 费用少，不等于交易少

13主题5日，初始10万元的同一历史账户：

| 指标 | 趋势立即切换 | 趋势累积调整v2 | 分散对照 |
| --- | ---: | ---: | ---: |
| 累计费用 | 5,491.63元 | 1,570.03元 | 545.21元 |
| 交易笔数 | 608 | 945 | 314 |
| 短持费卖出笔数 | 64 | 37 | 0 |
| 实际年化波动 | 8.92% | 8.82% | 9.22% |
| 平均基金市值/总资产 | 79.92% | 67.35% | 91.23% |

小步调整可能产生更多小额订单，费用因成交金额与短持情况变化而下降，不能把净收益差机械等同于省下的费用。当前没有模拟每单最低佣金，也没有ETF交易单位/真实行情，不能将这些笔数和费用直接套成ETF表现。平均暴露更低，也使回撤改善不能全部归因于趋势预测。

最长宽基5日v2实际年波动约5.61%、平均暴露54.44%，分散对照约6.91%/96.86%；较低风险和较低收益有明显暴露差异，尚未完成严格风险匹配的趋势增量证明。

首个牛市模型尚未拟合，2015至2016只在后段开始拟合，不是完整的新模型牛熊检验。2021至2023熊市改善值得保留，但均值和分散参照更好；2017与2019至2020的牛市也有明显少赚。不能事后只在熊市启用渐进、牛市启用立即切换。

独立重新开户与连续持仓不同：最长宽基趋势v2在2021至2023熊市，20日新开户+0.30%/连续切片+2.85%，5日新开户-1.90%/连续切片+1.16%。新开户使用已知结束日的最后7日入场保护、末日退出；连续账户不会按阶段结束日提前调整。两种收益不混用，也不将各阶段重新开户收益相乘。

13主题只覆盖最后三个观察段，缺少前六段共同历史。5日趋势v2连续账户在2025上涨观察段+27.63%、2026下跌观察段+0.39%；均值分别+27.51%、+1.22%，分散分别+28.36%、-0.02%。2026同段独立新开户趋势为-3.38%，不能因为连续切片略正就宣称此策略熊市必赚。2024至2026仍称观察段，不把2026作为完整熊市。

## 7. 核验与复现

两轮共684次账户回放，含重新核算的对照，不是684个独立投资策略：v1为64个主账户、208个压力账户、184个新开户；v2为16个累积目标主账户、16个旧渐进对照、104个压力账户、92个新开户。v1另引用184个已冻结的新开户指标，不计为新运行；v2立即切换/分散分段参照明确标记为引用，不冒充重跑。

v1的32个立即切换主账户与上一轮完全一致。v2的16个旧渐进主账户指标与v1完全一致，证明新动作没有暗改旧动作。所有账户通过独立现金/FIFO/完整退出、训练成熟/预测、当前实际份额与风险退出、候选组合、成本代理及选择核验；v2还核对上一实际决策的目标及累积时钟。552个连续切片另行从净资产曲线计算收益/局部回撤一致。

157项相关测试通过，其中14项新增渐进测试，包含保留实际类内比例、真实时间差、不能渐进保留失效类、风险先减、未拟合回退、候选/风险/退出篡改拒绝、实际现金账本、门槛停滞复现、累积目标跨门槛及不得读未来计划。没有宣称全仓库测试通过。

两版协议摘要、源码快照、两份净值输入、日历与参考报告摘要核对通过。v2相对v1的源码变化仅限渐进动作、专用核验与回放接口三文件；旧v1源码快照仍保留，当前实现也能按v1协议重跑其旧动作。通用分配引擎、预测模型、原跨类信号/审计器与生产排名没有修改。

## 8. 下一步与限制

本轮已经确认两件事：只加入“不交易”没有稳定收益改善；渐进动作确实要与交易门槛兼容，不能每次清空尚未执行的目标。补测后仍没有证明趋势特征胜过均值对照，更没有获得适合各基金池的强收益方法。

下一步优先检验趋势的**可获利期限**：区分信号还在与实际净收益仍可获利，用成熟的不同期限样本评估预测是否有增量，再决定检查/持有窗口。实际短持费、确认、到账及持仓状态要进入决策评估，不能继续把固定60日毛收益当作全部经济价值。保留不交易和已核验的目标累积，但不按已知牛熊或最高历史收益择优组合。

后续已完成[可获利期限与净收益预测诊断](fund-net-horizon-predictivity.md)：3/10/20/60/120日，现金到账后才成熟，1,983个评估窗口及192个资金探针。20日两类均合格时有局部相对强弱信息，但净盈利筛选/幅度校准不足，尚无跨池稳定最佳期限；下一步需直接检验投资账户净收益增量，不将单位资产预测统计当作新投资回报。

本轮只是对[动态交易论文](https://w4.stern.nyu.edu/facdir/lpederse/papers/DynamicTrading.pdf)中渐进调整思想的本地研究启发，不是其二次成本模型的闭式最优策略，也没有估计或证明最优调整速度。论文的商品期货结果不移植到本项目。

历史反复查看、当前存续基金筛选、净值首次可用时点、分红权益/付款、真实历史费率与限购未完全核实等限制延续；预测10%波动不保证未来波动或最大回撤。未使用真实ETF行情，没有修改生产排名、数据库、实盘或提交代码。持续研究目标仍未完成。
