# 板块趋势计算方案与本地实验

实验日期：2026-10-12。版本：`sector-trend-experiment-v2`。

## 1. 结论和产品目标

本地日线足够支持计算板块的方向、路径质量、近期变化与多周期分歧。实验能够区分涨幅相同但路径不同、急涨后回落、大跌后修复等情形。单一趋势分仍会把近期转弱的板块排在前面，需要先判定状态，再在相同状态内比较分数。

后续收益检验没有发现稳定优势。当前适合定位为“趋势识别与观察”，预测未来持续上涨的能力仍待验证。正式页面和现有接口尚未切换算法；本次提供可复算的实验模块、脚本、测试与方案。

| 实验比较池 | 86 个同花顺原生行业，不混入指数与 ETF |
| 行业日线范围 | 2025-01-02 至 2026-10-12 |

| 最新 20/60/120 日可计算数量 | 各 86 个 |
| 被剔除的未完成日线 | 0 条 |
| 滚动样本 | 421 个“信号日期、观察周期、后续周期”组合 |
| v2 本地完整实验耗时 | 约 2.7 秒，含三周期滚动指标与后续检验 |

读取 SQLite 时使用只读连接和同一读事务，不启动采集、不执行迁移、不修改行情。信号只读取计算日及以前的收盘价，网格缺行或价格无效时该窗口不参与计算，不填零或插值。未完成行情不进入实验。输入日线摘要和交易日历摘要保存在 JSON 报告中，便于辨认复算是否使用同一批资料。

历史实验使用今天仍在库内的行业集合及当前存储版本的日线，无法还原历史目录变化或当时首次发布的数据。各时间段都在这次迭代中被查看过，因此分段结果不属于严格冻结后的样本外验证。

## 3. 三层计算

### 第一层：描述完整价格路径

分别读取 21、61、121 个收盘价，对应 20、60、120 个交易日变化。对 `log(价格/起始价格)` 回归，得到日斜率、拟合区间变化及 R²。使用相对价格避免指数点位高低影响比较。

主要证据如下：

| 证据 | 含义 | 使用方式 |
| --- | --- | --- |
| 区间收益 | 起点到终点的涨跌 | 展示证据，以及同组相对收益分位 |
| 拟合变化、R² | 整体方向及直线趋势解释程度 | 正负方向结合拟合程度评分 |
| 路径效率 | 净对数变化 / 每日对数变化绝对值之和 | 同样涨幅，来回震荡越多，效率越低 |
| 上涨日占比 | 上涨日记 1、持平记 0.5、下跌记 0 | 辅助描述持续性，避免持平全部被视为下跌 |
| 近期斜率、R² | 最后 5/15/30 日的方向与质量 | 捕捉当前转弱或修复 |
| 均线结构 | 价格相对近期均线、近期均线相对较长均线 | 对近期方向做交叉检查 |
| 区间及近期最大回撤 | 过去风险与当前回撤 | 过去风险扣分，近期回撤参与状态判断 |
| 日波动 | 每日对数收益标准差 | 识别高波动、缩放均线偏离 |

R²表示对过去路径的拟合程度，不是未来上涨的置信度。路径效率也不是上涨概率。该实验中的相对强度仅相对同组行业，没有接入宽基基准。

### 第二层：先给出趋势状态

状态判断有优先级，先检查转弱和修复，再检查下行、上行与震荡：

| 状态 | v2 实验规则 |
| --- | --- |
| 转弱 | 近期拟合变化 < -0.5%、价格低于近期均线，且整个窗口拟合变化或实际收益 > 1% |
| 修复中 | 近期拟合变化 > 0.5%、价格高于近期均线，且整个窗口拟合变化或实际收益 < -1% |
| 下行 | 整个窗口拟合变化 < -1%，且近期拟合变化 < -0.5% |
| 上行候选 | 整个窗口拟合变化 > 1%、近期拟合变化 > 0.5%，且价格不低于较长均线 |
| 高波动上行 | 上行候选且近期回撤至少 8%，或日波动至少 2.5% |
| 震荡 | 上行候选但整体 R² < 0.35 或近期 R² < 0.2；其余方向证据不足的情况也归此类 |
| 趋势增强 | 通过上行质量条件，近期日斜率比前一个不重叠近期窗口高至少 20%，且绝对增量 > 0.0002 |
| 稳定上行 | 通过上行质量条件且未触发上述增强或高波动条件 |

近期均线长度为 5/15/30，较长均线长度为 10/30/60。增强比较的两个近期窗口各含 6/16/31 个价格，允许共用衔接点，但不共用收益区间。

这些阈值是可审查的初始工程规则，并非针对未来收益搜索出来的最优参数。“震荡”在此包括方向尚未确认，不等于波动小。

### 第三层：同状态内用分数辅助比较

最初讨论的 30/25/20/15/-10 公式缺少因子量纲和分数范围，不能直接相加。本次把它归一化为对照组，并增加一个明确归一化的改进方案：

```text
原始趋势分 =
  20% 同组相对收益分位
+ 25% 整体方向与拟合质量
+ 20% 路径效率
+ 25% 近期方向与均线结构
+ 10% 上涨日占比
- 0 至 15 分风险扣分
```

所有正向因子统一为 0 至 100 分，50 为中性；最终截断到 0 至 100。主要定义：

```text
clip(x) = 限制 x 在 [-1, 1]
整体方向质量 = 50 × [1 + clip(拟合区间变化 / 2%) × R²]
路径效率因子 = 50 × (1 + 路径效率)

近期结构 =
  0.50 × clip(近期拟合变化 / 1%) × 近期R²
+ 0.25 × clip(价格相对近期均线偏离 / 波动尺度)
+ 0.25 × clip(两条均线的相对偏离 / 波动尺度)
近期因子 = 50 × (1 + 近期结构)
波动尺度 = max(0.5%, 日波动 × sqrt(近期交易日数))

回撤扣分 = 10 × clip01((最大回撤绝对值 - 5%) / 15%)
噪声扣分 = 5 × (1 - |路径效率|) × min(日波动 / 1%, 1)
```

收益分位按全行业的同日、同窗口、同网格计算；并列采用中点分位。有且仅有一个可比较对象时不虚构分位，剩余因子重新归一化。前端搜索与筛选不能重新计算全局分位。

试验中的“趋势领先候选”需同时满足分数至少 60、状态为稳定上行或趋势增强。高波动上行、修复与转弱应单独显示，不靠高分自动进入领先候选。不同周期分别计算，不直接平均三周期分数。

## 4. 测试方法

对比五组结果：区间涨幅前十、原始提案前十、改进趋势分前十、平滑趋势分前十，以及经过状态与 60 分门槛的候选。普通前十对照有意不加状态门槛，用来检验单一分数的局限。

每 5 个交易日产生一次信号，分别检查后续 5/20 日实际变化、相对同日全行业平均的超额变化、上涨比例、单板块后续最大回撤平均值，以及前十名单重合程度。另取间隔 20 日的信号检查，降低后续 20 日窗口重叠影响。未来数据只用于评价，任何行业未来缺行时整次评价跳过，避免根据未来数据是否可用选择板块。本轮没有此类跳过。

2025、2026 上半年、2026 下半年分别统计；跨分段边界的结果只进入全区间统计。2026 上半年各观察周期有 19 个后续 20 日信号；下半年各有 10 个。多个行业及重叠时间窗口存在相关性，不能把组合数量当成独立证据。

平滑试验：每 5 日锚点 `平滑分 = 0.5 × 当前分 + 0.5 × 上次平滑分`。首次采用当前分。这个规则是在五日更新频率下测试的，不能直接声称适用于每天刷新。

## 5. 实测发现及修正

### 状态识别比直接换排序更重要

最新日线的一些例子如下，名次比较池均为 86 个行业：

| 行业与周期 | 区间涨幅 | 涨幅名次 | 趋势分名次 | 趋势分 | 状态与证据 |
| --- | --- | --- | --- | --- | --- |
| 元件，20 日 | +2.76% | 8 | 45 | 36.8 | 转弱；最近 5 日拟合变化 -10.94% |
| 种植业与林业，60 日 | +25.16% | 1 | 14 | 60.6 | 转弱；最近 15 日拟合变化 -2.44% |
| 小家电，60 日 | +8.63% | 12 | 3 | 68.4 | 趋势增强；最近 15 日拟合变化 +9.07% |
| 元件，120 日 | +32.24% | 1 | 3 | 51.4 | 震荡；整体 R²仅 0.143，路径效率 0.078 |
| 风电设备，20 日 | +7.64% | 3 | 1 | 68.4 | 转弱；最近 5 日拟合变化 -1.95% |

最后一个例子直接说明：即使换成综合趋势分，旧上涨的证据也能让当前转弱的板块排名第一。产品需要把状态放在分数前面。元件长期排名仍靠前则说明“相对领先”不等于“绝对趋势良好”。

当前经过状态门槛的候选：短期只有小家电；中期有文化传媒、饮料制造、小家电、房地产、厨卫电器、物流；长期没有。应允许空结果，不能为了凑满十个而降低标准。

### 后续收益没有稳定改善

以下为各信号前十行业在随后 20 日的平均变化，再对信号日期取平均；它不是交易策略累计收益，也不是回测年化收益。

| 观察窗口 | 2026 上半年：涨幅榜 / 趋势榜 | 2026 下半年：涨幅榜 / 趋势榜 | 不重叠检查：趋势减涨幅 |
| --- | --- | --- | --- |
| 20 日 | +1.89% / +2.27% | -1.26% / -1.34% | -0.16 个百分点，20 个日期 |
| 60 日 | +1.22% / +1.16% | -3.43% / -4.03% | -0.73 个百分点，18 个日期 |
| 120 日 | +2.13% / +2.03% | -1.98% / -1.91% | -1.17 个百分点，15 个日期 |

趋势分在部分阶段减少后续回撤，也降低前十里当时已经转弱的比例；但没有持续提升后续涨幅。不重叠检查三个观察窗口的后续收益都低于涨幅对照。

状态门槛消除“转弱候选”是规则本身的结果，不能当作独立预测能力。更直接的反例：长期门槛组在 2026 下半年只出现一个可评价日期、一个候选，后续 20 日下跌约 27.86%。中期门槛组同一时段也只有 4 个可评价日期。当前上行结构无法保证下一阶段延续。

### 榜单平滑有收益，也有代价

名单稳定性采用相邻五日信号的前十集合交并比，越高越稳定：

| 窗口 | 涨幅榜 | 原始趋势榜 | 平滑趋势榜 |
| --- | --- | --- | --- |
| 20 日 | 39.55% | 30.74% | 48.25% |
| 60 日 | 58.81% | 54.08% | 67.31% |
| 120 日 | 69.25% | 63.28% | 76.51% |

平滑提升稳定性，同时延迟对转弱的反应。以短期全区间后续 20 日可评价日期为例，前十中当时转弱比例从原始趋势榜的 7.69% 增至平滑榜的 15.13%。建议状态直接采用最新窗口；是否用平滑分排序需明确接受这个取舍。

将相对收益权重从 20 改为 10 或 30，并等比例调整其余权重，最新三个窗口与基准前十各保留 9 至 10 个共同对象。这仅说明最新截面的局部权重敏感性较低，不能代替全历史参数稳健性验证。

### 从 v1 到 v2 的完善

v1 将整窗回撤至少 10% 或路径效率低于 0.2 直接判为高波动上行，最新三个周期均无稳定上行候选。低路径效率可以由小幅日常波动造成，而长期旧回撤也不能直接代表当前波动。

v2 改用近期回撤和日波动识别高波动，整体与近期 R²识别方向质量，保留旧回撤作为分数风险项。另增加平滑对照，并保留其延迟反应的负面证据。没有根据未来涨幅反复搜索权重来让结果变好。

## 6. 建议落地的页面与接口

页面三周期先展示“稳定上行/趋势增强”的候选，按原始趋势分排序；另外提供高波动上行、修复、转弱及全行业视图。每条显示状态、分数、近期方向、区间涨幅与主要风险，名称使用“趋势观察”或“趋势领先板块”。当前没有合格候选时显示空状态。

多周期一致性先做解释字段：三周期同向上行记为“多周期上行”；长周期下行而短周期修复记为“短期修复、长期偏弱”；长周期向上而短周期转弱记为“长期上行、短期转弱”。缺一个周期就标记缺项，不假定一致，不追加未经测试的综合分。

建议新增结构，保留原收益字段和收益排名作为对照：

```json
{
  "return_pct": 8.63,
  "trend": {
    "method_version": "sector-trend-experiment-v2",
    "state": "strengthening",
    "score": 68.4,
    "eligible": true,
    "leader_eligible": true,
    "as_of": "2026-10-12",
    "lookback_sessions": 60,
    "evidence": {
      "recent_sessions": 15,
      "recent_fitted_return_pct": 9.07,
      "r2": 0.594,
      "efficiency": 0.121
    }
  }
}
```

该 JSON 是建议契约，实验模块尚未输出完整生产接口。正式接入还需复用当前过期、采集失败、同源同身份、同日同网格门槛，生成状态内排名并测试筛选稳定性、历史展示隔离及候选空状态。无需新增采集即可实现价格趋势识别。

要继续验证未来延续性，先冻结公式、门槛及行业范围，在新产生的数据上前向积累信号，再评估分状态的延续率、回撤与有效样本数量。宽基相对趋势、量能扩散和市场宽度是后续可独立验证的证据，不属于本次已实现能力。

## 7. 复算与文件

```bash

```

- 实验计算：`backend/analysis/sector_trend.py`，未接入生产链路。

- 最新结果：`runtime/verification/sector-trend-experiment.json`。
- 第一轮结果：`runtime/verification/sector-trend-experiment-v1.json`。

结果文件属于本地运行资料，不作为固定生产数据提交。复算使用当时数据库内容，数据刷新后具体例子与数字可能变化。
