# 趋势收益预测与实际投资决策

更新：2026-10-14。数据截至2026-10-12。结论：**把趋势评分改为60日收益预测，再扣换仓成本，并未产生稳健的投资提升。** 本轮不是只回测一个默认日期：四个基金池、两种检查间隔、三类对照、日期/费用/执行压力，以及牛熊独立开户和连续账户分段都已核算。不能将预测准确率略升或个别回撤下降解释为可投资优势。

## 1. 本轮改变了什么

不再直接把过去涨幅最大者当作未来最值得投资者。新增两种滚动模型，共用相同投资约束：

- **均值对照**：仅用股票、黄金、债券三类身份预测历史收益，采用相同岭回归收缩、训练窗口和成熟条件。它仍受当前绝对趋势准入限制，不是完全无趋势策略。
- **趋势预测**：除类身份外，加入21/63/252日对数收益、60日波动、标准化趋势强度、上涨周期占比，以及63日斜率拟合收益、拟合度、效率和回撤，共13项特征。

标签是信号次日净值买入、随后持有60个交易日的实际基金毛收益。类内按初始资金等分、份额固定，现金分红不再投资；买入日分红不计入。标签不是免费每日再平衡的类指数收益，也不是收益除波动后的分数。净值内含产品费用仍然存在。

每10个交易日生成训练样本，只允许标签结束日不晚于决策日的样本进入拟合。使用过去1096自然日的特征日期，至少24个成熟观察日期，固定惩罚1。内部末20%验证清除未成熟标签，但该验证只记录，不用来事后启停策略。没有挑选最赚钱的参数、迁移其他池训练样本或补造新基金历史。

候选为现金、合格债券60%、合格股票或黄金60%加合格债券40%，以及两类均合格时的风险分散组合。股票、黄金、债券合格标准仍是三个收益周期至少两个为正。先按当前基金协方差统一缩减到10%预测年波动，再比较：

```text
候选收益估计 = 风险缩减后的各类资金权重 × 预测60日毛收益
成本估计 = 普通每边费率 × 各基金目标权重与实际持仓权重差的绝对值之和
选择依据 = 候选收益估计 - 成本估计
```

以上只是普通成本代理，不精确预测短持费、等待、到账和现金不足。真实模拟账户仍逐笔执行FIFO、普通每边0.1%、不足7确认自然日赎回费下限1.5%、普通7日等待、下一净值执行、T+1确认、T+2到账、分红现金和最终退出。现金不计息，不做空、不加杠杆，沿用3个百分点/25%再平衡带。60日标签**不意味着强制持有60日**；这正是后续需要检验的期限不匹配。

预测不足物理下限-100%时截断至-100%，不设置择优上限；资金收益差在1e-10以内才按名称稳定处理平局。尚无24个成熟日期时，两种模型都沿用原单赢家规则，明确记录为未拟合，不能冒充新模型预测。

另对两模型分别测试普通每边0.5%、1%和延迟到第二交易日执行，短持费仍为普通费与1.5%的较大者。13主题趋势5日收益降到15.28%、3.63%；延迟一天为23.24%，没有择优采用延迟方案。最长宽基5日普通1%仅+2.60%，回撤46.49%，不是平滑稳健的高费率策略。104个压力账户形成52个同条件模型配对，趋势收益胜过均值22次；账户相关，不是22次独立胜率证据。没有重算原规则/分散对照的全部压力组合，不据此声称逐个压力条件都胜过或输给它们。

## 6. 为什么尚不能投资，以及下一步

本轮可确认的事实是：点收益预测不充分；相同投资约束下，更复杂趋势特征没有稳定胜过均值对照。现代20日回撤下降，但真正拟合后仍亏损。预测60日却每5/20日重新选择组合、缺少精确的短费与到账预估，以及没有独立的不交易候选，都是当前实现限制；**尚未证明它们就是亏损的原因**。

下一轮优先研究“持续多久、调整多少”而不是继续增加评分权重：先用过去可见数据检验预测在不同期限的衰减，再让目标期限与检查/持有期限对应；将维持实际持仓作为合法候选，比较真实可执行的渐进调整与立即切换。绝对风险退出仍优先，不能为节约费用强制长期持有已转弱资产。不事后按基金池、年份或牛熊标签选参数。

这一方向参考[Garleanu与Pedersen的动态交易论文](https://w4.stern.nyu.edu/facdir/lpederse/papers/DynamicTrading.pdf)：其模型考虑预测衰减和交易成本，得到逐步靠近目标组合的策略。但论文基于二次交易成本并在商品期货验证，不等于本项目的按持有日阶梯赎回费、确认/到账、长仓约束；这里只取研究启发，不移植其收益，也不宣称下一轮必然有效。

宽基低摩擦投资载体路线也保留；是否纳入ETF的偏好尚未收到，不影响当前本地研究。没有把免费基金NAV情景当ETF实测。

后续已完成[保留持仓、渐进调整与趋势投资](fund-gradual-class-allocation-research.md)：两轮684次账户回放、157项相关测试，并复现/补测小步调整被门槛持续忽略的问题。13主题5日累积调整趋势收益+31.83%、回撤7.53%，好于本轮立即切换，但同条件均值+32.80%，较长历史也没有普遍收益优势。执行方式有所改善，不等于已证明趋势预测可投资。

## 7. 核验与复现

本轮143项相关测试通过，其中9项新增测试覆盖固定份额分红边界、过去特征、成熟标签、防未来泄漏、风险缩减资金收益、成本降低无谓切换、未拟合回退、模型/决策篡改拒绝、缓存样本一致性以及真实账户核验。不是全仓库测试通过声明。

320个新核算账户：32个主账户、104个压力账户、184个新开户阶段账户。每个账户通过现金/FIFO/完整退出、原始信号/目标风险及实际持仓核验；新模型的训练可见性、标准化、回归方程、内部清除验证、预测和候选收益选择另做重建核验。学习核验缓存仅在同池同模型、已核对且未改变的训练样本集内复用，不用于不同样本集。

184个连续切片用账户曲线另行计算收益和局部回撤一致。16个原规则/分散主账户指标与[完整退出修正后的费用报告](fund-trading-friction-diagnostic.md)完全一致；源文件差异仅为通用审计器允许经过专用预测重建的声明。协议、源码及快照、两份净值输入、修正日历、参考报告的摘要核对通过。预测诊断是额外描述性统计，非独立实盘或未查看样本外数据。

真实净值首次可用时间、分红权益与付款、产品历史合同及限购尚未全部核实；当前存续基金筛选有偏差，10%目标预测波动不保证未来波动或最大回撤。目标仍未完成，没有改生产排名、数据库、实盘或提交代码。
