## 2. 把描述性分数变成可检验预测

本轮没有把“80分”解释为80%盈利概率。使用15个价格与趋势特征：20/60/120日分数、5/20/60/120日收益、60日波动/回撤/均线偏离/效率/拟合度、大盘方向，以及方向与短期回调的交互。

标签为次日按净值买入、再持有20或60交易日后的扣费收益，减去当天同组股票基金的平均扣费收益；另一标签为该期间的净值加现金分红资产路径最大回撤。分红持现金，不虚构红利再投。现金分红权益登记和真实支付日仍是数据假设。

采用固定惩罚强度1的岭回归，标准化统计只用训练数据。数学计算使用本地NumPy的[线性方程求解器](https://numpy.org/doc/stable/reference/generated/numpy.linalg.solve.html)，没有新增依赖或将模型复杂度扫描到事后最好。

每次预测只使用此前1096自然日内的信号样本，而且每个标签的结束日必须不晚于预测日。每10交易日取样，至少24个不同信号日才启用；历史不足时明确回到基础组合。24个日期不是24份独立样本，资产之间和20/60日标签之间均有相关性。

内部验证取最新20%的信号日期；训练侧进一步剔除结束日在验证开始日或之后的标签。验证门槛版本只在过去内部排序相关性大于0.03时启用。这是固定研究规则，不是已校准的盈利概率或统计显著性门槛。

13主题共同历史较短，本轮首先从更早存在的9主题学习关系，再应用到当前池。初版发现预测参照仍是教师池的平均收益，迁移后可能把整个新池相对教师池的上涨误当成当前池内的优势。最新版本先减去当前股票候选的平均预测，再决定是否调整仓位。该修正及其失败结果均保留。

模型只调整20%资金的股票卫星，另外20%股票基础仓位不变；债券40%、黄金20%也不因一个选板块模型而归零。卫星最多3个，普通入场要求预测当前同组超额收益超过“0.2个百分点余量加两边普通手续费”。持有卫星低于负门槛时退出，允许迟滞以减少频繁切换。实际持有时间不一定等于训练标签期限，这也是下一轮要单独检验的限制。

回调方案另行维护卫星目标成员，不能把已有的被动底仓误认为“已满足回调入场”。长趋势失效或模型验证未通过时，释放卫星配置，资金回到基础股票分配，而非长期持现金错过整个市场。

## 3. 手续费压力结果不能误读

13主题池中，20日模型在每边0.5%或1%的压力情景反而回到基础组合附近。这不是费用越高收益越高，也不是费用被倒扣：已知费用提高后，入场优势门槛同步提高，弱预测不再触发换仓，策略实际更接近不做额外判断。

这说明不少预测交易在正常费用下仍拖累收益。不能挑选高费用情景的较高收益，宣称模型稳健。费用压力同时改变成本和策略的成本门槛，属于成本感知规则的敏感性测试，并非完全相同交易清单的纯费率差额。

另外保留检查起点偏移2/5/7交易日和两日后执行对照。它们没有消除13主题模型相对基础配置的劣势。预测日之前的所有特征和模型训练日期不随执行延迟偷看后续净值。

## 4. 再检查此前的风控改善

为避免只拿高股票仓位的被动组合做对照，保持上一轮20交易日检查、5个百分点偏差带，用固定规则把原40%股票和20%黄金同时缩到60%，剩余转入相同债券，即24%股票/64%债券/12%黄金。

| --- | --- | --- |
| 13主题加债券 | +18.46% / -10.43% | **+21.76% / -6.61%** |
| 9主题加纯债 | +29.43% / -12.03% | **+31.50% / -5.83%** |
| 4主题加纯债 | +36.77% / -11.09% | **+51.31% / -7.17%** |
| 长期股债金 | **+94.84% / -8.90%** | +90.79% / -11.11% |

长期股债金仍有局部趋势风控增益，但另三个池的固定低风险配置同时提高收益、降低回撤。此前“回撤减半”的观察不能单独证明趋势系统有明显优势。

同时保存风险缩放0.4/0.6/0.8/1.0的固定配比诊断，没有在事后按实际回撤挑一个参数作为可提前知道风险的投资配置。四个分隔子账户与单个被动账户的执行形态仍有差异，不能说风险和资金使用完全相同。

最新校准回测693个账户账本独立重建通过，预测另行从成熟记录重建训练集并核验标准化、岭回归方程及内部验证排序相关性。它们是重复使用历史的计算核验，不是693次独立实盘验证。

当前研究仍缺少真正未查看的未来区间、历史首次净值公布时间、逐基金合同费率及申购限制、真实分红到账证明。规则和模型结构都经过同一历史上的研究；不能把按时间隔离的回放称为完全未见样本外表现。实际费用可能更高，实际收益可能更差。

### 下一轮的具体方向

1. 对现代基金池测试本池已成熟样本训练，单独验证老池关系迁移是否是失效原因。当前预测特征最长只需要120日，不应自动沿用其他12个月策略的252日数据预热而损失可用训练历史。
2. 分开测试预测20/60日与实际卫星持有期限的匹配，避免短期预测进入后长期不再有优势，却因退出迟滞继续保留。
3. 验证趋势对整个权益风险预算的用途，而非只用于同组资产选择；始终保留同风险被动配置与费用对照。

持续目标仍为将趋势计算提升成有证据支持的投资策略，不以某个漂亮数字或测试数量宣告完成。当前不接入自动交易、不改线上排名，也不推荐用户照模型立即买入。
