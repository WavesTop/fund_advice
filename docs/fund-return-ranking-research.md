更新：2026-10-13。研究目标继续，尚不能据本轮推荐投资。去掉评分的波动分母后，最长宽基池出现更高收益和更低回撤，但主题池落后，宽基候选也没有通过检查时点和费用压力验证。没有只保留好看的主曲线。

## 1. 本轮只纠正一个结构

上一轮[信号诊断](fund-cross-asset-signal-diagnostic.md)发现，原标准化走势强度不等于预期实际收益，评分和单位风险标签的共同波动分母也可能使相关性看起来更好。

新规则 `dual_return60` 与原 `dual_leader60` 完全相同，只有股票/黄金的相对排序改为：

```text
收益强度 = 原标准化评分 × 当日带下限的过去年化波动
         = 平均(各周期对数收益 / sqrt(该周期交易日数 / 252))
```

它取消资产间的波动分母，仍保留原周期权重结构。不是预测校准，没有把它称为预期未来收益，也不是反向购买低分。21/63/252日至少两个收益为正才可参与选择；胜出股票/黄金类提议60%，债券合格则提议40%，不合格留现金；无风险类合格时债券合格给60%，否则现金。

原63日转弱退出只属于此前单独规则，本轮不叠加它。类内仍等权，不事后选最赚钱的板块。组合风险仍由真实投资基金过去60日收益协方差控制，所有目标等比例缩小至不超过10%预测年化波动，剩余现金不计息，不做空、不加杠杆。**预测风险约束相同，不代表实际波动或最大回撤相同。**

沿用252交易日预热、每20交易日检查、3个百分点/目标25%较小者的偏差带、下一净值执行、T+1确认、T+2赎回到账及FIFO批次。普通买卖各0.1%为情景；不足7确认自然日赎回至少1.5%，风险退出及末日清仓不免除短持费用。真实合同费用、限购、净值首次发布时间和完整分红支付时点仍未逐产品核实。

原11个规则全部保留，新增规则在本轮收益计算前限定，不搜索门槛或周期。报告采用已修正2018-12-31休市的研究日历，数据截止2026-10-12，旧报告保留。

每格为累计收益/最大回撤，全部已扣研究情景交易费用，不是年化。不同池的股票类及起点不同，不能跨行反选赢家或相乘。

现代池10万元约变124,737元，原规则139,031元。新规则203笔买卖、费用2621.83元、11次不足7日赎回；原规则144笔、1402.75元、1次短赎回。资产选择、风险缩放后的资金使用和费用都改变，不能把全部落后归因为手续费。

最长宽基账户的实际基金为华安黄金联接C（000217）、华夏沪深300联接A（000051）、嘉实中证500联接A（000008）、华夏纯债C（000016）。其10万元约变313,320元，原规则300,051元；收益多13.27个百分点、最大回撤少约5.31个百分点，年化收益9.93%对9.54%，实际年化波动9.16%对9.19%。这是可继续验证的域内候选，不能据主题池失败简单否定它，但也不能只凭这一条曲线宣布目标完成。

宽基池同风险预测上限的非趋势对照：三类等额+140.87%/-15.71%，固定黄金提议60%为+179.70%/-11.89%，无趋势逆波动+123.15%/-6.29%。候选比等额多收益且少回撤，但比高黄金预算回撤更大；对照实际波动及暴露不同，不称严格风险等同。

## 3. 对宽基候选单独追加验证

在看到宽基候选改善后，限定该域的进一步压力研究，不要求一个规则同时赢过所有不相同的股票池；也不把本次选域包装成事先未查看验证。

候选、原趋势、三类等额、固定黄金60%、无趋势逆波动五个规则全部用同一宽基池、共同2014-09-19至2026-10-12区间。重新核算主账户先与冻结报告完全一致，再测费用、检查网格和执行延迟。

普通费率上升，原短赎回最低1.5%仍有效。改费用不改排序规则，但会影响现金和后续数量，不是完全固定交易清单的逐笔加费。

候选每个压力场景并非都输给原排序：高费用下仍比原排序好，部分情景回撤也较低。然而对低换手参照的优势不稳定。默认检查网格213.32%不能当成投资人普遍能取得的收益，10日错位后的回撤24.43%也再次说明10%预测波动不是未来回撤保证。

候选长历史300笔交易、累计研究费用12645.81元、4次短赎回；三类等额137笔、998.34元，固定黄金132笔、1157.88元。累计费用不是收益差异的完整归因，持仓路径及资金基数也不同。

## 4. 短、中、长期入场窗口

宽基池分别146/48/24个20/60/120交易日重开户窗口，所有窗口按已知期限留末7确认自然日的入场限制。与无限期主账户末日统一清仓的经营假设不同。表内均值不能相加、当年化或替代连续账户收益，窗口和资产之间仍相关。

| 规则 | 20日平均净收益 | 60日平均净收益 | 120日平均净收益 |
| --- | ---: | ---: | ---: |
| 新收益强度排序 | +0.63% | +2.55% | +4.76% |
| 原标准化排序 | +0.62% | +2.44% | +4.61% |
| 三类等额 | +0.38% | +1.71% | +3.51% |
| 固定黄金60% | +0.52% | +2.03% | +4.12% |
| 无趋势逆波动 | +0.33% | +1.49% | +3.19% |

候选相对原排序的均值改善约0.00/0.10/0.15个百分点，远小于整段曲线给人的观感。候选20/60/120日最差净窗口分别-5.24%/-6.88%/-11.06%，原排序-5.24%/-5.69%/-7.66%；60/120日尾部亏损更大。盈利比例分别60.27%/68.75%/70.83%，并非所有入场时间盈利。

年度重新开户也不能替代连续持仓曲线。宽基候选2021年+1.52%、2022年-8.01%、2026年截至10月12日-1.40%；2022年固定黄金为+2.29%。不能只强调长历史累计正收益而忽略亏损阶段，也不能将重开户年收益相乘伪造连续账户。

## 5. 验证与后续行动

42项直接相关测试通过，新增测试证明取消波动分母只影响排序，不放宽准入、不叠加退出规则；原未来数据隔离、目标风险及独立重建测试同时覆盖新规则。

四池12规则研究928个账户、宽基追加1125个账户，全部独立重建现金、应收、FIFO份额、确认日、短赎回及终值，并从过去原始基金价格重建类信号、提议权重及实际投资基金协方差约束。两批是计算核验，不是2053次独立实盘。

原11规则的433个主要/年度/压力账户指标及原窗口摘要完全不变；宽基追加的五个主账户也与冻结报告完全一致。源码、协议、净值输入、修正日历和参照报告的内容摘要核对通过。未变更生产排名、数据数据库，未提交代码、未下单。

目标仍未完成。下一步重点检验固定20交易日网格的择时敏感性，区分初始入场等待、趋势切换迟到、风险缩放和到账后再投资的影响；再评估明确的日历检查或事件触发机制，而不是挑默认相位的高收益。宽基候选继续保留，主题池的失败也继续保留。

仍缺真正未查看的独立区间，以及逐产品历史合同费用、限购、真实可用净值发布时间和分红支付证据。假设和回溯选择风险不能靠账本核验消除。没有把“去掉波动分母”当成已解决收益预测，也没有用不含趋势的配置代替最终目标。
