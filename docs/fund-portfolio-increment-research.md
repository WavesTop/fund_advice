# 板块增仓的账户净收益增量

后续：[从真实持仓评估局部调仓](fund-holding-action-diagnostic.md)。新增账户接续和不平仓估值后，本篇24个主账户已逐个复现完整原结果；新诊断不再以全账户清仓为局部动作的标签前提。

更新：2026-10-14；净值截至2026-10-12。接续[净收益期限诊断](fund-net-horizon-predictivity.md)。本轮将目标从预测资产自身收益，改为预测一个板块增仓方案相对基准账户的实际模拟净收益差。

**结果不支持采用这一版策略。** 四个基金池中，加入趋势特征的模型都没有胜过基础状态模型或同规则基准。更明显的问题是，为使投资动作匹配20日标签而反复将整个账户平仓，带来了费用、空仓等待和风险退出摩擦。真实资金标签更接近决策目标，但不应为生成方便的标签强制改变理想的投资方式。

## 1. 投资方案和标签

基准为股票类合计40%、黄金20%、债券40%。各基金自身21/63/252日总收益至少两段为正才投入，否则该份预算留现金；不将空出的份额重新分配。过去基金协方差统一缩减到10%预测年波动，单只股票基金上限35%。

候选为股票类等分20%、某个合格板块基金额外20%、黄金20%、债券40%；另有不增加板块、保留额外20%现金的选项。保留“没有可靠正增量时继续基准”。实际选择时不允许增仓不合格板块，标签则完整记录各候选在该时点按准入规则执行后的结果。

每10个交易日，从10万元现金分别模拟基准及各候选。20日窗口内仅初次投入，不按分红再买入；每天按当时已知的净值、当前实际份额计算风险与基金自身趋势失效，必要时减仓。末日实际FIFO退出，计普通每边0.1%、不足7确认自然日赎回费下限1.5%、T+1确认、T+2到账、3个百分点/25%带及现金约束。风险减仓按实际风险超限或持仓基金自身失效支持，不把普通排序变化伪称风险退出。

训练标签为：

```text
净收益增量 = (候选账户累计净收益百分比 - 同期基准账户累计净收益百分比) / 100
```

不是板块自身涨幅，不是股票同组平均收益之差，不是免费指数收益。初始资本相同，实际费用、风险减仓和分红现金均已进入账户结果。标签只在预定20日退出的T+2日期成熟；提前全部退出也不提前拿来训练。增量不是资产收益率，不套用-100%的物理截断。

## 2. 学习与持续账户

只用各基金池本地样本，过去1096自然日、至少24个成熟观察日期、固定惩罚1，内部清除验证只记录，不用于事后启停。

- **基础状态模型**：基金/现金身份、当前可增仓性、股票/黄金/债券准入比例、基准/候选初始风险缩减比例、该基金过去60日波动。
- **趋势模型**：相同基础状态，加11项已有过去特征：20/60/120日评分、5/20/60/120日收益、60日回撤/均线偏离/效率/拟合度。波动不重复作为另一回归基项；现金候选用当时股票组特征均值。不增加外部指标、模型依赖或新资产。

未拟合时用基准；已拟合时只在可选候选预测增量大于1e-10时增仓，按预测值选最高，极小平局稳定处理，否则仍用基准。不是自动把任意最高分板块视为值得买入。

持续账户为与标签匹配的20日现金周期：从实际入场决策日起持有，期内只执行必要风险减仓，到期全退出，等待成交及T+2到账后才开始下一周期。默认从决策到下次可入场为23交易日；执行延迟到第二日则24日。提前全部风险退出仍等原周期现金日期。最后几日风险订单可能阻挡到期时，直接关闭已成熟持仓，避免把尚未到账款当作新资金。

这是一种明确可验证但较强的实验约束，**不是已证明最优持有间隔**。同规则基准、基础模型和趋势模型共享该现金周期及每天安全检查。额外参照包括无准入过滤的40/20/40、无准入过滤的股票/黄金风险分散60%加债券40%，以及已经核验的不强制周期全退出的分散账户。

## 4. 摩擦与风险不能混为预测价值

13主题完整账户：

| 指标 | 同规则基准 | 趋势模型 | 周期分散 | 不强制周期退出分散 |
| --- | ---: | ---: | ---: | ---: |
| 累计费用 | 6,280.64元 | 5,801.98元 | 8,127.58元 | 499.44元 |
| 交易笔数 | 805 | 909 | 1,408 | 234 |
| 短持费卖出笔数 | 194 | 265 | 176 | 0 |
| 实际年波动 | 6.01% | 6.88% | 8.62% | 9.34% |
| 平均基金市值/总资产 | 54.43% | 51.93% | 82.63% | 91.68% |

即使计划持有20日，风险退出也可能在最初几天发生，不能因此取消短持费。更多小额风险减仓、周期全退出和重新买入，以及保留现金都会改变真实路径。最长宽基周期分散累计费用33,462.10元，不强制周期退出参照1,664.27元，收益分别76.62%与164.38%。不能把这两个差额简单归因于费用：风险检查频率、暴露、现金等待和时点也不同。

本轮没有把实际波动不同的账户视为严格风险匹配，也没有因更低暴露就将回撤变化完全归功于趋势。现金周期问题值得进一步单独消融，当前结果只证明这版整体不足，不证明某个单一因素解释了全部亏损。

## 6. 核验与压力

4,408个训练用真实模拟账户，其中718个基准、3,690个板块/现金候选；不是4,408个独立投资策略。每个账户都通过现金/FIFO和独立每日检查核验，共88,160次每日检查。记录直接从候选与基准最终净资产重建，收益差和到账成熟日另行核对，得到两模型共7,380条训练记录。

另有24个完整持续账户、56个压力账户、138个独立新开户账户，共4,626次账户回放；138个连续切片另行重算收益和局部回撤一致。压力为普通每边0.5%/1%、初始入场延后1至4日、执行延迟到第二交易日。延后入场不是“初始相同的检查相位”；模型训练标签仍用基线0.1%，高费用明确是合同费率误差压力，不伪称已重新按高费用学习。

50项直接相关测试通过，其中12项新增：真实周期/延迟等待、初始及每日风险目标、板块/现金预算、过去特征独立重建、遗漏每日检查拒绝、目标/现金时钟/退出理由篡改拒绝、账户净资产差与到账成熟标签、NaN拒绝、未来标签不能改变过去拟合、真实已拟合预测/选择核验，以及临近到期风险订单不阻挡退出。没有宣称全仓库测试通过。

来源摘要、协议、净值输入、修正日历、源码快照和参考报告核对通过。公共分配引擎、原信号/预测模块未改；没有改生产排名、数据库、实际交易或提交代码。

## 7. 下一步

本轮应保留“学习实际投资增量”的目标，但拒绝将20日全账户平仓作为理想策略。更合理的下一步是以持续持仓为基准，比较“维持当前实际持仓”与“只调整必要板块”的未来净资产增量，而不为产生训练标签额外卖掉健康核心仓位。

这需要正确保留历史份额年龄、现金、待到账款和排队订单，不能拿现金新开户标签冒充已有持仓的换仓收益。评估窗口结束可以只是净资产计量日，不必是强制赎回日；未来退出成本、风险监控和实际到账仍需明确核验。新的方法尚未实现或被本轮结果证明，不据此承诺投资收益。

净值可用时点、真实历史产品合同/限购、分红权益/支付、当前存续池选择、反复查看历史与样本相关等限制延续。10%预测波动不是未来波动/最大回撤保证。本轮未使用真实ETF行情，不能推荐投资，持续寻找目标仍未完成。
