# 板块分析底层数据支撑

- 更新日期：2026-09-19
- 适用范围：同花顺 90 个行业主池、板块机会页和后续基金映射。
- 接口契约：`GET /api/sectors/opportunities` 的 `data_support`，版本 `sector-data-support-v1`。

## 1. 目的

本文件列出形成短、中、长期板块判断所需的底层数据、当前实现程度、使用边界和接入顺序。覆盖率只说明资料是否存在且完整，不是评分、胜率或推荐条件。价格、经营、估值、事件和基金暴露彼此独立；一个维度可用时，不能替另一个缺失维度填值。

## 3. 分周期最低数据要求

| 判断范围 | 最低支撑 | 缺失时的行为 |
| --- | --- | --- |
| 短期，未来约 1 周至 1 个月 | 完整 20 日价格窗口、回撤、市场宽度、成交扩散、带首次公开时间的催化和当时预期、相对宽基表现 | 只有价格时仅保留走势观察，不输出买入方向；成交额不解释为资金净流入 |
| 中期，未来约 1 至 3 个月 | 完整 60 日价格窗口、当前完整成分、当期与去年同期的收入和归母利润、公告可用时间、订单／销量／库存等兑现指标 | 样本不全时披露分母和遗漏公司；不以 60 日涨幅替代经营方向 |
| 长期，未来约 3 至 6 个月 | 完整 120 日价格窗口、至少两个可比报告期、经营现金流、行业专属指标、有明确方法和业务日期的估值、同口径历史 | 缺任一核心维度时维持“长期依据待补齐”；不能仅凭 120 日排名推导长期价值 |
| 正式基金推荐 | 上述行业判断、基金真实暴露与生效日期、跟踪质量、流动性、费率、申赎和交易规则、个人约束及样本外验证 | `formal_recommendation_ready=false`，不把观察池项目改名为推荐 |

## 4. 数据契约

所有新增数据必须同时保存下列信息：

1. **对象身份**：来源、原始代码、分类版本、适用行业或证券；禁止只用名称连接。
2. **双时钟**：业务日期和系统取得时间；报告类数据另存公告时间及其精度。
3. **原始口径**：来源字段名、单位、累计／单季、总市值／流通市值、PE 类型、亏损样本处理和复权口径。
4. **完整性分母**：预期页数、预期证券数、实际数量、缺失／排除原因、是否截断；部分结果不得标记完整。
5. **修订与历史**：原响应哈希、解析版本、分类与成分版本、修订关系；不能用今天的成分回填历史估值或经营数据。
6. **可用范围**：每个字段明确能支持的周期和不能支持的结论。未知值保持未知，不用零、均值或旧值代替。

`data_support.datasets[]` 统一使用以下状态：

- `available`：该数据项对全部目标对象满足当前完整性要求。
- `partial`：存在真实资料，但对象、成员或字段分母不完整。
- `not_collected`：尚未接入或没有任何合格观测。
- `blocked`：已尝试，但身份、时点、口径或来源质量校验未通过。

## 5. 接入优先级

### P0：直接阻断当前中长期判断

1. 解决超过 100 只成分行业的合法完整分页或正式数据服务，同时保留页数和数量闭环校验。
2. 接入同花顺个股报表：收入、归母利润、经营现金流、报告期、公告日期及修订；按当前成分披露覆盖分母。
3. 核验同花顺“市盈率”的具体类型、业务日期和亏损处理后，再保存当前估值；至少累计 60 次且跨度 365 天的同成分同口径观测，才计算描述分位。
4. 建立催化／预期事件事实表，保存首次公开时间、适用对象、状态和失效条件，禁止事后回填最新新闻。
5. 选择并固化统一宽基基准，增加同日期网格的超额收益、Beta、波动和下行风险；池内名次继续单独保留。
6. 为相对收益补充分红、拆分和指数收益口径；不把不复权价格变化命名为总收益。

### P1：提高短期解释力和样本质量

1. 保存同花顺行业摘要的上涨、下跌、平盘／停牌分母、成交量和成交额；确认净流入算法前只保留原始字段，不命名为真实资金申赎。
2. 获取官方权重或明确权重不可得；流通市值只能作为独立资料，不能静默转换成官方权重。
3. 为银行、证券、保险、多元金融及周期行业配置专属指标和时效规则。
4. 接入基金持仓、跟踪基准、关系生效日期、跟踪误差、流动性、费率与交易规则。

### P2：研究增强与验证

加入盈利预测修订、订单／库存／价格、融资与拥挤度等资料；随后建立不可变研究快照、样本外对照和失效条件统计。只有验证完成后，才讨论正式候选或参数调整。

## 6. 三套资料时效与估值要求

当前代码存在三种用途不同的资料时效，估值另按交易日判断，不能混成一个数字：

- 人工行业背景快照：超过 **45 个自然日**停止作为当前行业判断，只供核对旧资料。
- 固定时点研究事实：经营事实超过 **150 个自然日**标记过期，用于研究快照复算。
- 当前成分报表样本：最近已结束报告期距当前超过 **185 个自然日**时停止使用，以容纳季度结束到法定披露之间的时间；公告时间仍必须不晚于计算时点。
- 估值：必须等于最新完整交易日；历史分位另需至少 **60 次观测且跨度 365 天**。

这些阈值是当前保守产品规则，不是收益验证后的最优参数。调整时必须同时修改实现、测试和本文。

## 7. 初步历史验证

2026-09-19 已完成[现有价格优势榜的初步历史验证](sector-price-validation.md)。独立验证数据集通过同花顺年度日线扩充为90行业、417交易日、37,530条记录；生产库仍为原140日快照。这些历史价格不补齐本文件列出的经营、估值、事件或基金暴露缺口。

固定规则及次日观察起点下，短期18个不重叠批次平均落后行业等权对照0.82个百分点，中期5批落后0.76个百分点，长期2批领先10.80个百分点。短、中期在该样本中没有表现出平均筛选优势；长期样本不足，不认证投资有效。当前行业池回放、来源修订、非基金总收益及非样本外限制见完整报告，正式推荐状态保持关闭。
