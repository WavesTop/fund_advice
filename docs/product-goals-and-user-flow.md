# 基金投资建议工具：产品目标与用户流程

- 更新日期：2026-09-12
- 阶段状态：本阶段暂时完成，已确认当前产品目标和大致使用流程。
- 文档定位：第一阶段的产品目标和用户侧需求记录，只确定产品要帮助用户完成什么，以及大致如何使用。

## 1. 产品目标

开发一个面向 A 股相关基金和板块的投资建议与决策复盘工具。用户可以查看短期、中期和长期全部三个周期的分析和建议，无需先选择某个周期。

产品围绕三个同等重要的目标展开：

1. **发现投资机会**：提供较全面的基金库，让用户直接浏览和搜索，通过 K 线图或净值走势了解基金历史表现，查看基金公开披露的持有股票及集中板块，并了解短期、中期和长期的板块机会。
2. **辅助投资决策**：结合用户持仓、仓位和投资要求，推荐基金、给出各周期的建仓、增仓、减仓、持有或暂不操作建议，并说明依据。
3. **持续复盘与策略改良**：完整保留系统当时的建议、用户自己的决定和实际操作，持续跟踪用户实际投资结果与遵循系统建议的模拟结果。用户能够查看收益差异、回顾双方判断；系统进一步检查原策略或方法可能存在的问题，提出有依据的改良方向，并持续对比原方案与修订方案的表现，检验改良是否有效。

决策记录、收益对比和复盘是首版的核心能力，也是用户持续使用产品的重要目的。产品需要让用户清楚地回答：系统当时建议了什么、自己实际做了什么、两者结果相差多少、原有方法哪里可能有问题、可以如何调整，以及调整后表现如何。

策略改良是复盘的进一步目标。系统应能依据实际记录自我检查、提出候选修订，并通过对比验证和持续观察形成后续改良方向。

## 2. 投资周期与首版范围

系统同时提供以下三个周期的分析和建议，用户侧全部可见。各周期按本产品约定划分：

| 分析与建议周期 | 时间范围 |
| --- | --- |
| 短期 | 一周以上、一个月以内 |
| 中期 | 1–3 个月 |
| 长期 | 3–6 个月 |

上述为本产品的周期名称和范围。本版记录区间，不展开交界日期的具体归属和日期换算。

首版涵盖 A 股相关基金和 A 股板块。用户在支付宝、微信、同花顺等渠道购买的相关基金，也是希望能够查询和分析的对象。

当前实施范围为单人项目、个人使用，仅在自己的电脑上本地部署和访问；不纳入多用户服务或云端部署。基金数据更新需要联网，已有数据可在本地保留和查看。

## 3. 用户需要的核心能力

### 3.1 查询基金，查看走势、持有股票和板块

- 软件需要事先具备较全面的 A 股相关基金库，覆盖绝大多数用户需要查看和搜索的基金。
- 用户可以直接浏览基金库，通过基金名称或代码搜索，并辨认具体基金及份额类别。
- 仅当少数基金未收录、用户搜索不到时，由用户提供基金代码，系统根据代码查询并补充该基金信息，使其能够被查看和搜索。
- 基金详情需要展示该基金的 K 线图，支持查看不同历史时间范围，帮助用户了解走势，并与持有股票、集中板块信息一起查看。
- 图表需标明展示的是交易价格还是基金净值，以及对应日期。具备真实开盘、最高、最低、收盘行情的基金展示交易 K 线；仅有每日净值的基金展示净值走势图并明确标识，不将净值或估算值冒充真实交易 K 线。
- 系统需要获取基金信息，向用户展示公开披露的持有股票，以及该基金主要集中的行业或板块。
- 板块判断应结合基金的投资内容；ETF 联接基金需要结合其投资的目标 ETF 了解对应股票和板块。
- 展示所依据的持仓日期、范围和板块归属依据，让用户知道信息反映的是哪个时点、哪一部分投资。
- 公开披露持仓可能滞后，展示内容不承诺为实时完整持仓。

### 3.2 发现有潜力的板块

- 板块潜力分析是产品核心功能。
- 同时展示短期、中期和长期值得关注的板块，用户可以查看全部三个周期的判断。
- 展示判断依据、主要风险及数据时间。

### 3.3 获得适合自己的基金推荐

- 将板块机会匹配到具体基金。
- 分别从短期、中期和长期，结合用户的风险要求、资金条件和现有持仓，推荐适合用户的基金，并展示各周期的推荐理由。

### 3.4 录入持仓和交易规则

浏览和搜索基金时无需先录入个人持仓。需要获得持仓建议时，用户从基金库选择自己的基金，再提供个人买入记录和交易规则。基本信息包括：

| 信息 | 用户提供的内容 |
| --- | --- |
| 基金名称 | 从基金库中选择并确认已购买的基金 |
| 买入时间 | 该笔投资的买入时间 |
| 买入金额 | 该笔投资的投入金额 |
| 交易规则 | 该基金不同持有期限对应的赎回费等规则 |

- 同一基金多次买入时，保留各笔买入记录；后续实际发生的建仓、增仓和减仓也需要记录，供持仓分析和决策复盘使用。
- 支持记录用户提出的费率情形，例如持有不足 7 天赎回收取 1.5%，部分基金持有满 7 天后免赎回费，部分基金在满 7 天、不足 30 天时仍收取 0.5%。
- 上述费率为需要能够记录的示例。实际交易规则按具体基金、份额类别及适用规则记录，不能统一认定满 7 天后免赎回费；免赎回费也不等于免除所有费用。

### 3.5 获得针对持仓的操作建议

- 基于用户持仓、仓位、投资要求及板块分析，同时提供短期、中期和长期的操作建议，用户可以全部查看。
- 支持建仓、增仓、减仓、继续持有和暂不操作。
- 说明建议原因，结合用户情况确定调整方案，并考虑用户持有时间和该基金的交易规则。
- 同一个板块机会，对不同用户可以产生不同操作建议。

### 3.6 决策记录、收益对比与持续复盘

这项能力与板块机会分析、个性化投资建议同等重要，需要贯穿用户的投资过程。用户应能清楚查看以下内容：

| 用户需要了解什么 | 产品应提供的内容 |
| --- | --- |
| 系统当时建议了什么 | 对应基金、建议时间、短中长期周期、建议操作及理由；保留当时的内容，后续新建议不覆盖旧建议。 |
| 我自己决定了什么、实际做了什么 | 用户的决定和实际操作，以及与系统建议一致或不同的地方；用户可以补充自己的判断理由。 |
| 两种选择目前分别表现如何 | 用户实际投资结果，以及遵循系统建议的模拟结果；对应的短、中、长期建议分别标明，供用户查看和比较。 |
| 收益相差多少 | 在可比的资金和时间条件下，展示实际与模拟的收益金额、收益率及差异，标明比较期间。 |
| 回看整个过程能了解什么 | 将收益表现与当时的建议、决定、操作和理由放在一起，帮助用户发现值得总结的决策差异，并回顾一段时间内的整体表现。 |

- 区分“用户做出的决定”和“已经发生的实际操作”。选择采纳建议后尚未实际操作，也应如实记录。
- 用户可以记录全部采纳、部分采纳、未采纳以及暂不操作等情况；不同选择都应保留，供后续回看。
- 实际投资结果和系统建议的模拟结果应明确标识；收益比较也应让用户看懂对应期间的投入资金，避免把资金投入差异误认为投资表现差异。
- 用户可以持续查看结果变化，并回到历史记录复盘。用户实际结果优于或落后于系统模拟结果时，都应如实展示，帮助用户同时评估自身决策和系统建议。
- 本版确定上述用户可见能力，具体模拟和计算方法留待后续设计。

### 3.7 发现策略问题并提出改良方向

当原有策略或方法出现可能的问题时，系统应主动结合决策记录与结果进行复盘，帮助用户理解问题，并提出可以验证的修订方向。这里的改良同时服务于用户自身的投资方法和系统提供建议的方法。

| 环节 | 用户应能看到什么 |
| --- | --- |
| 发现可能的问题 | 哪些决策或持续表现值得检查、对应哪个周期，以及支持这一判断的记录；可能涉及板块判断、基金选择、仓位安排或交易费用等。 |
| 提出改良方向 | 原方案拟修改什么、为什么修改、适用条件及可能的取舍，让用户理解原方案与候选方案的区别。 |
| 对比验证 | 在可比的时间、资金和费用条件下查看原方案与候选方案的表现，明确标注模拟结果，并展示收益与风险方面的变化。 |
| 持续跟踪 | 查看修订后的后续表现、仍存在的问题，以及继续观察、保留原方案或再次修订的理由。 |

- 结合对应投资周期、多次决策和持续表现判断是否需要改良；一次亏损或一次落后只能作为观察线索，不能直接认定策略失效。
- 问题原因尚不明确时，应标明为可能原因，不能把收益差异直接当作某个原因已经被证实。
- 不把在用于修订的历史记录上表现更好直接认定为改良有效，还需要通过未参与修订的记录或之后新发生的表现继续验证。
- 原策略、原建议及其结果应继续保留。后续若采用修订方案，应让用户看到修改内容和开始使用的时间，历史记录不因策略更新而被改写。
- 改良后效果更好、更差或证据不足，都应如实展示；效果不佳时可以提出恢复原方案或再次修订的方向，不承诺每次修订都能提高收益。
- 本版确定“发现问题、提出改良、对比验证、持续跟踪”的用户侧能力。候选方案何时替换当前策略，留待后续产品设计明确。

## 4. 大致使用流程

1. **直接浏览或搜索基金**：软件已提供较全面的 A 股相关基金库，用户可以直接查看，或按基金名称、代码搜索。
2. **补充少数缺失基金（如需要）**：当基金未收录、搜索不到时，用户提供基金代码，系统据此补充基金信息。
3. **查看基金走势、投资内容与板块机会**：进入基金详情，查看 K 线图或净值走势、公开披露的股票和集中板块，同时查看短期、中期和长期有潜力的 A 股板块。
4. **提供个人持仓和要求**：用户从基金库选择自己的基金，录入买入时间、买入金额和交易规则，并提供投资要求。
5. **查看各周期的推荐与操作建议**：系统结合用户仓位、要求和交易规则，分别给出短期、中期和长期的基金推荐及建仓、增仓、减仓、持有或暂不操作建议，三个周期的结果全部可见。
6. **留下当时的决策记录**：系统保留当时的建议、理由及对应周期；用户记录自己的决定、是否采纳和实际操作，也可以补充自己的判断理由。
7. **持续查看收益对比**：用户查看实际投资结果，以及遵循短期、中期和长期系统建议的模拟结果，了解可比期间内的收益差异及其变化。
8. **回顾决策并复盘**：用户结合结果回看当时双方的判断、操作和差异，总结自身投资过程，并评估系统建议的表现，为后续决策提供参考。
9. **查看策略改良方向**：系统指出原策略或方法可能存在的问题，说明依据，提出候选修订及适用条件。
10. **跟踪改良效果**：用户查看原方案与候选方案的对比和后续表现，了解修订是否带来改善，形成下一轮复盘的依据。
