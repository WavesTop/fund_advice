# 等待到期复查：小幅执行改善，尚非策略突破

账户更正：下列冻结收益可能受完整退出残余及额外检查影响，重算前不作为当前已核验收益，见[完整退出状态更正](fund-full-exit-precision-correction.md)。

更新：2026-10-14。研究继续。继[真实持仓风险与费用感知退出](fund-cost-aware-exit-research.md)之后，本轮增加持有等待结束后的新信号复查。四池、牛熊分段及压力测试显示：部分收益和回撤改善，但固定20日下影响很小，仍未解决调仓日期敏感性或稳定超额收益。

后续已完成[多时点趋势仓位合成及高频检查对照](fund-phased-class-trend-research.md)，现代池局部改善，但未稳定胜过无趋势同预算配置；本页保留等待到期实验的冻结结果。

## 1. 规则与边界

只有实际普通卖出因份额未确认或不足7确认自然日而被挡住，才登记该批次的复查请求。从阻挡日之后找最早的决策日，使下一净值执行时份额已确认、赎回确认与购入确认相隔至少7自然日。只使用购入日期、交易/确认日历和既定执行延迟，不读取未来净值。

到期读取最新趋势评分、绝对准入及真实组合风险，再计算新目标；不保存旧目标待执行。最新趋势反转可以不卖。已有待执行订单时保留到期请求，等不重叠的下一决策日；份额已被卖掉则删除该批次请求。多个批次同日到期只触发一次组合复查。

真正的绝对趋势失效或实际持仓预测风险超标仍允许提前卖出，并照常扣至少1.5%的短持费。临近模拟末日、没有新订单执行空间时，不绕过末日清仓费用。普通费率仍为每边0.1%的研究情景，T+1确认、T+2到账、FIFO、现金不计息和10%目标预测风险不变。

这是一项可关闭的研究选项 `review_on_holding_release`，默认关闭，未修改生产板块排名或数据库。它不是定时盲目卖出，也不是延迟风控；7日来自已有模型设定，没有搜索等待期限。真实合同的短持费、确认口径及费用门槛仍未逐产品历史核实；其他设定下到期不一定等于低费率。

最长池10万元约变326996元，比此前约326596元只多399元，跨越约12年；最大回撤没有改善，费用从12345.24元增至12361.08元。不能把227.00%当作普遍收益或将这点差异称为显著提升。

单赢家四池固定20日的阻挡批次请求/实际到期复查日分别3/2、6/4、2/2、3/1。少量新增检查解释了影响较小；请求和复查不是一一对应，因为可以同日合并或批次提前被风控卖出。

## 4. 日期与费用压力

最长池固定20日、所有相位保持同日初次入场，只错开后续检查。每格为收益/最大回撤；无趋势对照在该池没有到期请求，本轮指标与此前一致。

| 检查网格 | 单赢家到期复查 | 同预算无趋势 |
| --- | --- | --- |
| 相位0 | +227.00% / -14.30% | +164.38% / -8.86% |
| 错开5交易日 | +138.46% / -14.38% | +154.94% / -8.95% |
| 错开10交易日 | +127.65% / -22.80% | +160.13% / -8.46% |
| 错开15交易日 | +117.40% / -18.34% | +163.15% / -8.21% |

三个错位仍低于无趋势配置。相比此前真实风险规则+138.67%、+126.06%、+121.58%，改进有正有负，没有消除网格选择风险。

普通每边0.5%时，最长单赢家20日+168.31%/-15.58%；每边1%时+98.47%/-17.30%；T+2净值执行+180.94%/-15.68%。事件机制同费率压力分别+4.56%/-44.30%、-47.79%/-66.68%，仍不适合作为当前成功方案。13主题20日高费用收益+18.52%/+10.88%，T+2为+40.23%，不能事后为每池挑最有利的延迟。

## 6. 核验与研究方向

73项直接相关测试及54项共享实验调用方测试通过，共127项。新增9项覆盖到期后采用最新目标、反转时取消原卖出、风险退出仍扣短费、默认关闭不改账户、未来净值隔离、日历/旧目标篡改拒绝、待执行订单不丢失请求、提前风控卖出取消死批次、末日无执行空间仍扣短费。修复了测试编辑时断言位置错误，没有削弱或移除原断言；未宣称全仓库通过。

报告共282个模拟账户：24个旧完整对照、24个到期复查完整账户、96个压力账户、138个阶段新开户。全部完成账本、过去信号/目标风险和真实持仓核验；258个新选项账户另核对登记批次、确认日历到期时间、待执行订单约束、实际复查日期及新目标与信号记录一致性。138个持续账户切片独立重切一致，旧24个完整指标与冻结报告完全一致。源码快照、协议、两个输入、研究日历和参照文件摘要核对通过。这些高度相关模拟不是282次独立实盘。

等待到期复查作为执行机制保留，但不继续将细微等待调整当作主要收益突破路线。下一步检验“分散检查时点”：把多个错开的趋势判断合成一个真实账户的目标仓位，保留共用现金、FIFO及费用，而非平均已有收益数字或挑最赚钱相位。还需要单独对照纯粹提高检查频率，并保留当前绝对趋势失效及真实风险处理。

这一方向参考[Newfound关于趋势调仓时点分散的原研究](https://blog.thinknewfound.com/2018/04/diversifying-the-what-how-and-when-of-trend-following/)，但这里的共享账户目标合成只是待验证推论，不是对其美国市场示例的复制，更不搬用其收益。作者也明确指出分批调仓需考虑交易成本，见[Tranching, Trend, and Mean Reversion](https://blog.thinknewfound.com/2020/04/tranching-trend-and-mean-reversion/)。降低日期依赖不等于创造超额收益；中国零售基金短持费、到账和共用批次必须实际模拟。

研究目标仍未完成，未改生产排名、数据库，未下单或提交。仍为反复查看的存续基金历史，未完成逐产品历史费用、可用净值时点、限购及真实分红支付核实，没有未查看的样本外区间。
