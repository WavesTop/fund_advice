# 投资分析与建议：分阶段开发与复查计划

- 更新日期：2026-09-15
- 对应范围：整体技术架构 §3.3，实施要求以[投资分析与建议开发文档](investment-analysis-design.md)为准；数据能力依赖[基金数据与存储计划](fund-data-storage-plan.md)。
- 当前进度：A0—A6 小阶段仍未开始；按用户补充范围实现的轻量入口见 §1.4。当前真实数据及人工核验行业背景不能据此认定完整版本、历史快照、披露、交易规则及分析材料已经可用。当前优先补齐展示、真实研究入口与关联核查，见 L2；正式推荐能力仍未验收。
- 使用方式：按小阶段执行，每项完成必要实现、测试和交付说明后，交由用户复查，再进入下一项；用户明确授权连续执行时，以该授权范围为准。

## 1. 执行与复查规则

### 1.1 一次执行的范围

1. 默认一次执行一个小阶段，例如“执行 A0.1”；只指定大阶段时，从该阶段第一个满足前置条件的未完成项开始，交付后等待复查。
2. 每项必须同时完成该功能所必需的实现、调用方调整、契约同步、针对性测试和自查。发现单项过大时，先在本计划内拆分编号，不能把必需处理留到后面却提前宣称完成。
3. 用户复查提出的问题在本项内修正并重新交付；“继续下一阶段”可同时表示接受当前交付并启动下一项。明确连续授权覆盖的范围内持续执行，每项仍保留独立的验证结果。
4. 编号表示推荐实施顺序，实际执行以各项前置能力为准；不存在“上一编号通过即可跳过其他依赖”的规则。AI 与界面分支可在契约稳定后穿插，具体关系见第 2 节。
5. 依赖不足时，可以在当前授权范围内完成不依赖缺口的契约、夹具或本地逻辑，但不得把替身服务当成真实接入。交付说明保留具体缺口，正式依赖未满足的部分不能标为通过；默认不自行转做另一小阶段。
6. 本计划只拆分 §3.3。数据采集、事实版本及快照复用 §3.2；正式账本、计费、执行模拟及实际操作记录属于 §3.4；长期策略复盘与启用流程属于 §3.5；完整启动器、密钥配置和运行管理属于 §3.6。不在本轮另造上述服务。
7. 提交和推送按当次用户明确指令执行；编写或通过本计划不构成代码实现、自动提交、自动启用策略或交易执行的授权。

### 1.2 状态定义

| 状态 | 含义 |
| --- | --- |
| 未开始 | 尚未实施，可以先核对前置条件。 |
| 进行中 | 正在完成本项实现与验证。 |
| 待复查 | 本项实现、自查及必要验证完成，等待用户复查。 |
| 待修正 | 用户提出复查问题，留在本项修复。 |
| 已通过 | 用户已接受该小阶段的交付；不代表已经证明投资效果。 |
| 受阻 | 必要数据、接口或外部条件有明确缺口，说明原因、影响和已完成部分，不视为通过。 |

下方小阶段表是实施状态的唯一记录位置。大阶段只有在所属小阶段全部通过后才算完成。实现状态、数据适用性、研究结论和策略投资验证状态分开：技术检查通过不能将“研究试验”自动升级为“已验证推荐”，也不保证正收益。

### 1.3 每次交付给用户的内容

每项完成后在对话中说明：小阶段编号及结果、主要修改文件和阅读顺序、契约或数据库变化、实际运行的测试及结果、最短人工复查步骤与预期表现、剩余限制。已有计划只维护对应状态，不另建开发过程或阶段交付流水文档。

纯后台阶段提供固定样本、输入输出及复现入口；有界面的阶段提供可打开页面和操作路径。复查入口以本次实际实现为准，不提前编造命令。数值、时间和资金相关变更须能定位独立算例；涉及研究效果时，同时呈现基线、失败结果、样本范围和不确定性。

| A5.3 真实研究与候选页面 | 未开始 | A2.4、A3、真实序列和已存在的页面基础；AI 展示仅依赖实际已启用能力。 | 接入三周期结论及风险、证据和真实走势、按发布日期排列的事件，再下钻到原值、来源及算法；展示经营／估值／市场反应／质量、冲突、未知、数据日期、研究资格和变更理由。保留演示隔离与空／错／过期状态。 | 从页面选任一结论可追到快照、原文和计算值，三周期同时可读；事件不按报告期提前放入历史；断网或研究未接通不退回演示建议，置信度不显示为胜率，真实净值不搭配虚构历史分析。 |
| A5.4 个性操作与历史建议页面 | 未开始 | A4.3、A5.3；§3.4 的决定与实际操作入口。 | 接入个人条件确认、金额／仓位草案、费用和可模拟状态；展示建议有效期、触发／退出、失效及约束变化。历史页读取保存的原建议与当时依据；“采纳建议”“记录实际操作”分别连接对应职责。 | 复查部分采纳、未采纳、暂不操作、条件修改、建议过期和不可成交；查看旧建议不重算覆盖；采纳不自动记账或形成真实成交，多周期结果不造成重复扣款，操作状态与 §3.4 一致。 |

大阶段退出条件：AI 提取／判断和本地结果的身份、来源与失败状态清晰；页面完整展示已经具备的真实能力。AI 尚未接通时可单独交付 A5.3，但不得宣称 A5 全部通过。
