# 从真实持仓评估局部调仓

后续：[连续底仓、局部趋势仓位与退出间隙](fund-trend-satellite-research.md)。已将这些动作放入连续账户计算完整历史资产，不再将分支增量当作策略收益。

## 结论

本轮不再为了生成20日标签而全账户清仓，改为从同一个实际持仓检查点比较继续持有、局部板块调整和减仓到现金。较丰富的股票基金池出现小幅20日优势，但四组的60日平均增量均为负。不能据此推荐投资，不能把独立分支的收益连乘成策略收益。下一步重点是局部仓位的退出和机会衰减，而不是把排名第一永久持有。

数据截至2026-10-12。报告：`runtime/verification/holding-action-diagnostic-v1.json.gz`；方案：`config/holding-action-diagnostic-v1.json`；复现：`.venv/bin/python scripts/diagnose_holding_actions.py`。

## 方法

- 母账户：股票40%、黄金20%、债券40%，每只基金过去21/63/252交易日正收益至少两票才投入；股票单只上限35%，过去协方差预测波动超过10%时向现金缩放。每20交易日更新核心目标，其余日期只做风险检查，没有例行到期全平仓。
- 每60交易日取一次实际账户状态，共117个信号日期，各评估20/60日，共234个窗口。保留实际份额、购买日期、终身批次编号、可用现金、待到账款、既有订单及其原始信号。继承订单先执行，不撤销过去的交易来美化新策略。
- 对照仅维持健康仓位和每日安全退出。板块动作原则上从其他股票仓位移出10个百分点到指定基金；无股票供体时才在股票40%预算内申请利用现金。另有股票减仓10个百分点到现金的动作。
- 目标仍受自身趋势、35%单只上限及10%预测波动约束。普通持有期、调仓带、实际现金可能使动作部分成交，不虚构买入资金。
- 单次请求与分步完成并列：后者保留初始目标，待实际资金到账再尝试，直到目标板块进入3个百分点/目标25%的容差带。每日风险优先，目标板块失效时取消意图；资金修复期间其他健康目标也可能调仓。不是无限追随新的第一名。
- 按已有60日趋势评分选择当日合格股票基金第一名，比较其账户增量、合格基金动作等概率均值、现金动作和继续持有。事后最优只用于诊断，不用于选择。
- 估值日为信号日后H+1交易日，按基金净值计价，待到账款计入资产，不强制卖出健康仓位、不伪造退出费用。结果是净值估值收益，**不是全部已经到账的现金收益**。

分步方案是在首次单次请求检查后新增的探索，不是事先注册的独立验证。两种方案均保留四组和两个周期，没有挑选收益最高的参数。

## 验证与限制

研究费用情景保持普通每边10基点、确认持有不足7自然日赎回至少150基点，T+1确认、T+2到账、普通7日等待、3个百分点/25%调仓带。真实历史合同、净值发布时间、分红资格和支付日未全部核实；不是ETF价格回测。

1524个局部分支、4个母账户、12个实际历史接续、24个旧主账户兼容回放，共1564次账户运行。独立核账重建FIFO、费用、现金、分红与待到账资产，并由母账户已执行记录和既有决策重建检查点来源。四组各首/中/末三处接续逐笔匹配完整账户曲线、交易和最终状态。24个旧主账户保持完整结果一致，不只是收益近似相等。

专项及相关回归139项通过，未宣称全仓测试通过。源快照及冻结输入、参考报告、交易日历、方案摘要保存在报告，本轮只允许旧参考中的引擎与核账器变动。旧报告保留自身代码快照，不要求其摘要等于当前代码。

检查点只覆盖账户，不自动保存策略内部意图或模型。这类策略接续必须另存内部状态。目前拒绝持有期释放回调及已知终点买入防护的检查点模式，不假装正确继承。

下一轮比较持有、局部减仓、换仓、现金以及重新评估间隔。优先检验20日的小优势能否被只使用当时信息的退出条件保留，不能事后知道最佳卖点。必须再放回连续账户，和静态配置比较累计收益、回撤、周转及牛熊分段。

这些数据已反复研究，基金池有存续偏差，四组相互重叠；60日步长的60日标签因执行日期有边缘重叠。没有独立外样本或可信统计显著性结论。过去10%波动约束不保证未来波动或回撤。
