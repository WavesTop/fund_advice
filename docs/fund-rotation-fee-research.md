# 基金手续费与扩展回测

更正：后续发现研究日历遗漏2018-12-31休市。本页跨该日的旧4主题、黄金及长宽基轮动数字尚未全部用修正版重跑，不再作为当前已核验收益依据；2024起13主题与2020起9主题结果不受影响。见[估值与日历修正](fund-valuation-trend-research.md)。

日期：2026-10-13。结论：不能直接把趋势排名当成可靠的基金买卖策略。原规则转到真实基金净值并加入短赎回费用后，表现不理想；低换手组合规则有所改善，但尚无独立样本外的收益证据。所有结果为历史模拟，不保证未来盈利。

后续持续研究已加入被动同池对照、逐批目标仓位、债券和年度走步验证，详见[持续研究记录](fund-strategy-search.md)。新测试表明，正收益不等于胜过简单配置，原 +28.53% 不应单独用于判断策略有效。

## 2. 手续费与执行口径

- 持有天数 = 赎回确认日减去申购确认日，按自然日，而非交易日、申请日之差。默认确认T+1；另测T+2。
- 持有不足7天，赎回费按1.5%与普通赎回费的较高者计算，不是普通0.1%再加1.5%。满7天不触发该短期费，但不等于所有基金自动免赎回费。
- 普通申购和赎回各0.1%为研究情景；另测各0.5%和1%。未逐只、逐历史时期验证合同，不把情景费率当成基金真实完整费率。
- 此处按用户要求，将不足7天1.5%的规则用于全历史压力测试，并未重建每个年份的法律费率。
- 用当日已知净值计算信号，下一交易日按该日净值执行。假设上一日净值在下一次下单截止时间前已公布，未取得历史首次公布时间证明。
- 赎回到账默认执行日后2个交易日；另测3日、7日。未到账的资产保留为应收款，但不能用来再次申购。期末资产可能包含尚未到账的款项，不代表截止日全部现金可提现。
- 净值中已经体现的管理、托管、销售服务费用不重复扣除。额外平台折扣、申购限制、暂停申购、额度限制和实际到账差异尚未复原。
- 信号使用分红调整后的价格路径，持仓按原始单位净值计价，推断分红计入现金应收。分红从累计净值与单位净值差额的正变化推断，实际权益登记日和支付日未逐条核实。
- 风险止损及大盘转弱仍可触发不足7天赎回，不能假设一定免掉1.5%费用。下单后按次日净值成交，不保证能按止损阈值成交。

确认日与自然日的口径参见[深圳证监局说明](https://www.csrc.gov.cn/shenzhen/c105614/c7521978/content.shtml)。2026年费用规则另有分档及指数基金等约定例外，应核对[现行规定及附件](https://www.csrc.gov.cn/csrc/c101954/c7606091/content.shtml)和所买基金合同，而非一概认定7天以上免费。

## 4. 改进候选的固定规则

不再改公式去追逐最高历史收益，当前冻结如下：

1. 综合分为50%短期、30%中期、20%长期趋势分；入场55，退出45。
2. 自身价格高于60日均线、最近30交易日收益为正，才允许进入候选。
3. 权益基金要求沪深300代理净值高于200日均线；黄金仅豁免这个权益大盘门槛，仍必须满足自身趋势和分数条件。
4. 每10交易日检查补仓，最多10个持仓；每次新买入预算为信号日资产的10%，受现金约束，不因只出现一个候选就自动满仓它。
5. 日常分数转弱或低于120日均线且30日收益为负，普通退出等待持有满30自然日；它是策略选择，不是基金法定锁定期。
6. 20%移动回撤止损、大盘风控退出不等待30天。退出后冷却10交易日。

历史小基金池的上限取 `min(10, 基金数)`，因此4基金池每笔预算上限25%，单基金诊断可全仓；这些不是与13基金池完全相同的分散组合，不能合并成独立样本或用单基金收益代替组合收益。

20/60/120日固定期限账户另设：若距已声明的终末赎回不足7个确认自然日，不再新买入。这利用已知投资期限，不利用未来市场价格；连续全历史账户不使用此期限规则。

## 6. 多次测试与稳健性

共保留11组规则，分别比较综合/短/中/长期信号、6个历史池，并为多个方案保留滚动期限窗口；早期失败结果不删除。

冻结的10持仓候选在13主题共同历史：

| 情景 | 累计收益 | 最大回撤 |
| --- | ---: | ---: |
| 普通买卖各0.1%，不足7天卖出1.5% | +28.53% | -7.57% |
| 普通买卖各0.5%，短赎回下限不变 | +22.52% | -7.71% |
| 普通买卖各1%，短赎回下限不变 | +15.42% | -8.14% |
| 确认T+2、资金T+3到账 | +28.48% | -7.57% |

将10交易日检查周期起点依次平移0至9个交易日，收益范围 +15.57% 至 +28.53%，最差回撤 -9.44%。都是正收益，但依赖调仓日期，不能挑出最好日期宣称稳定性。到账T+3/T+7在这组10持仓账户未改变总收益，不说明实际到账时间永远无影响。

集中到3持仓，13主题收益升到 +68.95%，但回撤扩大到 -17.51%；5持仓 +35.05%、回撤 -11.67%，检查日期变化后最低收益约 +7.47%。因此没有把历史最高收益的集中方案当作默认方案。

新候选是在多次查看同一及扩展历史后选择的。尚未保留未查看的样本外区间，未证明跑赢被动同池组合，也未计算统计显著性。当前基金存续名单存在幸存者和主题选择偏差，历史订阅限制未复原。尤其2016起样本的短中期收益余量很小，不能认定跨市场稳定获利。

## 7. 核验与复现

- 40项针对性自动测试通过：确认日自然日边界、节假日、替代费率、未到账现金、止损仍收短赎回费、分红、自身趋势及黄金例外、已知期限保护、极小申购、篡改账本拒绝，以及原轮动和趋势测试。
- 最终全方案报告独立重建并通过16,997个账户账本；冻结配置另外重放并通过1,121个账户账本。两者许多账户重复，绝不能把这个数量当成独立投资样本。
- 验证器从原始单位净值、交易份额、费用及日期重建现金、应收、持仓、资产和回撤，校验费用和T+1下单。通过核账证明计算一致，不证明未来有效或数据假设完全真实。
- 原始数据、研究日历、执行代码和冻结参数的内容摘要记录在结果内。运行不改基金净值数据库，不接入实际交易，也未替换生产网页排名。
