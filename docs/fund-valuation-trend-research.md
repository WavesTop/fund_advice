## 1. 新数据与口径限制

按年度读取仓库已使用的中证公开查询接口，归档沪深300与中证500的2009至2026-10-12历史响应，以及官网链接的指数单张和估值文件。沪深300原响应4330行，中证5004331行，不等于这么多有效估值交易日。

- 每个指数有670个原始空估值值，最早正值2011-06-28，不能声称估值自2009年完整可用。
- 修正日历后，沪深30018行、中证50019行是非交易日记录，单独排除。中证500包含2018-06-18休市日。日期有值不等于可交易。
- 两个指数都缺2009-12-31、2010-12-31；不造值、不插值。按完整市场日历对齐后每个序列668个空值，包含缺行及源空值，不作为零估值。

接口字段名是 `peg`，没有直接把它解释成通常的PE/增长率。核对[沪深300官网](https://www.csindex.com.cn/#/indices/family/detail?indexCode=000300)与[中证500官网](https://www.csindex.com.cn/#/indices/family/detail?indexCode=000905)链接的原始单张：2026-09-30“滚动市盈率”分别为13.15和25.09，与接口同日字段相等。两页单张均渲染检查了日期与字段位置。

但当日XLS估值文件的P/E1、P/E2分别是沪深300的14.34/16.35、中证500的28.44/30.34，与滚动值不同，不能混用。[官网每日板块页面](https://www.csindex.com.cn/#/dataService/indexDashboard)也分别列静态与滚动市盈率。尚未取得完整指数计算细则及历史版本，不把行业V1.1说明直接套成指数方法。

因此本轮只把该字段作为**经同日单张交叉核对的候选滚动估值**进行条件研究，不宣称全历史语义与口径完全确认。原始响应为今天下载的历史版本，首次公布时间与历次修订未独立验证；推迟使用不等于消除了修订偏差。未接入产品或提供实时买卖建议，产品使用与再发布许可仍需核查。

## 2. 先修正交易日历

[上交所2019休市通知](https://www.sse.com.cn/disclosure/announcement/general/c/c_20181220_4696473.shtml)明确2018年12月30日至2019年1月1日休市。旧研究日历只在2019年记录1月1日，遗漏了2018年12月31日。基金可能在年末保存估值，但不能因此把该日用于申购、赎回、确认或交易日步进。

新日历另存为 `config/research-exchange-calendar-2009-2026-v2.json`，默认基金研究入口改用新版；原文件保留，以重建旧报告。新旧日历2009至2026交易日集合仅差2018-12-31一天，应用生产日历不改。

这会同时影响持有天数与换仓相位。例如2018-12-28买入、2019-01-04卖出，按T+1正确确认日为2019-01-02和2019-01-07，相差5自然日，触发短赎回费；旧错误日历会把买入确认放到2018-12-31，错误计算为7天。

在相同固定40%股债金、10%预测波动控制下，独立重建旧账户再对比修正版：

| 同一规则、同一资金起点至2026-10-12 | 旧日历累计收益 | 正确日历累计收益 | 差异 |
| --- | ---: | ---: | ---: |
| 13主题加3债券，2024-01-09起 | +34.95% | +34.95% | 0 |
| 9主题加纯债，2020-10-23起 | +44.22% | +44.22% | 0 |
| 4主题加纯债，2016-01-06起 | +74.79% | +74.13% | -0.66个百分点 |
| 宽基/黄金/纯债四资产，2014-03-12起 | +137.54% | +140.69% | +3.16个百分点 |

旧日历两个长账户复算与归档结果相等后，才测修正版；不能把这项日期修正造成的收益变化算作估值或趋势增益。现代账户及其指标回看不跨2018年，结果保持不变。

前几轮的长期模型、旧4主题轮动等其他规则尚未全部用新日历重跑。那些旧数字只保留作研究版本记录，不继续据此主张长期趋势有效。

## 3. 本轮限定的投资规则

估值仅作为整体股票风险预算，不把大盘PE冒充医药、半导体或机器人自身的PE，也不替换主题收益排名。

每个信号日，估值至少延迟1交易日；只允许额外陈旧不超过3交易日的已知报价，另测2/5日发布滞后。历史参照最多取报价之前1260个市场交易日，要求至少252个正值，且窗口内从首个正值起有效覆盖至少95%；当前报价不进入历史参照。相同值按中位秩计算分位，分别计算两个指数再平均，不用今日全历史分位回填过去。

两指数共同条件最早在2016-09-01满足。此前仍保留资金账户：估值预算回到基础40%，混合方案回到原价格质量预算，而不是利用后来数据决定删除早年。旧4主题和四资产估值单因子账户分别有20和80次决策缺少完整估值参照，不能称全期都按估值操作。

在看到本轮收益前限定七规则，历史本身已查看，不包装成独立预注册或样本外研究：

| 规则 | 波动约束前股票提议预算 |
| --- | --- |
| 三个固定参照 | 30%、40%、50% |
| 价格趋势质量 | 35% + 25%乘60/120日回归方向与拟合度 |
| 估值预算 | 60%减40%乘估值分位，范围20%至60% |
| 估值且趋势确认 | 分位不高于20%且趋势正时50%；分位不低于80%且趋势负时30%；其他40% |
| 估值/趋势混合 | 两种提议预算等权平均；估值未知时用价格质量预算 |

黄金提议20%，剩余配置同池债券，单债券上限90%，不能配置的部分留现金。全部规则使用过去60交易日协方差与10%预测年化波动约束，股票和黄金共同缩放。这不是未来波动或回撤保证，债券也不是无风险现金。

每10交易日检查；绝对3个百分点与目标金额25%的偏差带取较小者；普通买卖各0.1%为情景，不足7确认自然日赎回至少1.5%。确认T+1、资金到账T+2、期末全赎回、现金不计息；沿用真实基金净值及推断现金分红，不拿指数点位当实际基金利润。

## 4. 现代主题结果

13主题加3债券，2024-01-09至2026-10-12，10万元起始。均为上述情景扣费后的累计收益，不是年化或实盘。

| 规则 | 累计收益 | 最大回撤 |
| --- | ---: | ---: |
| 固定40%股票 | **+34.95%** | **-8.88%** |
| 固定50%股票 | +35.20% | -9.00% |
| 固定30%股票 | +30.70% | -8.27% |
| 价格质量预算 | +32.91% | -8.74% |
| 估值预算 | +32.85% | -8.14% |
| 估值且趋势确认 | +34.43% | -9.17% |
| 估值/趋势混合 | +34.04% | -8.20% |

估值预算少赚约2095元、降低回撤约0.74个百分点；混合预算少赚约904元、降低回撤约0.67个百分点。属于风险与收益取舍，不能称“极大提升投资策略”。趋势确认版收益与回撤均弱于固定40%参照。

增大普通买卖成本至各0.5%时，基础40%、估值、确认、混合分别为32.96%、30.45%、32.46%、32.14%；各1%时分别为30.34%、27.29%、29.73%、29.80%，没有挽救结果。

把估值使用滞后改为2/5交易日，估值预算为32.35%/32.99%，混合为33.58%/33.96%；确认版仍34.43%，没有一致优势。相位5估值预算38.30%高于同相位基础36.07%，但原相位32.85%低于34.95%；不能事后挑最好的换仓日。

## 6. 验证与下一步

98项相关测试通过，新增覆盖：历史分位排除当前值、延迟与3日陈旧上限、缺值不插值、1260日参照上限、未来数据不改变过去信号、原始接口身份校验、预算回退与共同风险约束、独立重建拒绝篡改，以及跨年休市的确认日/短赎回费用与基金非交易日估值排除。

最终版本679个方案账户逐笔独立重建账本，逐决策核验只用过去原始报价、重建历史分位及实际规则预算，并从过去净值收益重建风险；另复算2个旧日历基准账户。检查均通过。首版与最终版全部主要账户指标相同，源代码及协议摘要另保存并核对。多次复算不是独立投资证据。

研究目标继续进行中。当前新信息只是大盘整体估值，不足以解释不同主题的相对机会。已核查本地13主题基金的当前业绩基准，除黄金外均有具名中证主题指数；下一步应核各主题指数的实际发布日期、历史估值和基金基准沿革，不使用发布前回溯指数、今日成分股或当前财报制造过去可知信息。仍需可靠样本外验证，不能仅因下一轮某个历史数值更高就认定策略有效。
