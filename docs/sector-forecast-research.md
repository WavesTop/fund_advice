# 三周期板块预测与排序检验

日期：2026-10-15。接续[同池长历史检验](sector-long-history-research.md)，服务于 `/sectors` 短、中、长期优势板块推荐。本轮未修改生产接口、排序、试用快照或用户持仓。

## 结论

三个期限分别学习未来价格变化，仍未得到可替换正式榜单的策略。模型的预测误差小于历史均值对照，但主排程三个周期均落后于简单涨幅排名。长期虽胜过原趋势分，却未胜过涨幅；短、中期还弱于不使用当前走势特征的历史均值排序。误差下降不等于候选名单改善。

## 固定方法

- 固定使用上一轮全部86行业，截止2026-10-14，全池共同历史从2019年开始。更早缺口和九个评估阶段保留，不换基金池、不称未见样本外。
- 20／60／120日各自回看、训练和评价，不共用模型或混合分数。信号次日收盘作为观察起点，再持有对应期限。
- 两个预测输出为行业绝对价格变化、减同日全行业等权变化的相对差额。后者为正不代表实际盈利。
- 固定每10交易日一个训练锚点；仅全池完整日期形成记录。退出后下一交易日才成熟，退出日必须早于拟合日；只取1096自然日内且成熟的标签。
- 至少24个成熟日期才拟合，不足时明确未拟合，不填零、不用涨幅策略代填模型成绩。86个行业不能算86次独立市场。
- 复用仓库 `fit_ridge`，训练集归一化、标准差下限1e-8、归一化截断±5、惩罚固定1；训练窗、日期门槛和步长沿用既有预测研究，不搜索超参数或按验证指标择时启停。
- 特征11项：收益、近期拟合变化、整体／近期R²、效率、上涨日比例、回撤、日波动、近期均线偏离、均线差及同池收益分位，全部来自信号当日及以前。没有历史财报、估值或事件数据。
- 协议 `config/sector-forecast-research-v1.json` 在拟合结果前固定，主排程／每五日重叠补充排程完全沿用参考报告。相对预测在当前全池去均值，不改变排名；不把预测当作盈利概率。

八组比较为：原涨幅前十、原趋势前十、原状态名单、逐行业成熟历史相对收益均值前十、新模型相对预测前十、同一原状态集合改用新预测排序、预测绝对变化超过0.2%且相对变化为正的前十、与该正预测名单同日同数量的涨幅名单。0.2%只是固定往返20基点代理，不是实际基金合同或净收益。
